# Agent Plan 链路验证计划

> 日期：2026-05-09 | 目的：验证 Agent plan 三优先级全流程

## L3: 新建模板（Agent 自主判断策略）

后端必须引导 Agent 完成 `plan(action="create")` 并保存。

| # | 指令 | 预期策略 | 通过标准 |
|---|------|---------|---------|
| L3-1 | "生成4张不同风格的猫的图片" | parallel | 新建 parallel 模板，并发4张图 |
| L3-2 | "一步步画出猫：先草稿，再细化，最后精修" | iterative | 新建 iterative 模板，顺序3张图 |
| L3-3 | "生成一套可爱表情包：害羞、笑、哭、睡觉4种" | radiate | 新建 radiate 模板，锚点+4张图 |

## L1: 直接匹配（复用 L3 模板）

Agent 应自动匹配已有模板，`plan(action="apply")`，不创建新模板。

| # | 指令 | 复用 | 通过标准 |
|---|------|------|---------|
| L1-1 | "生成4张不同风格的狗的图片" | L3-1 | 匹配 parallel，改 subject="狗" |
| L1-2 | "一步步画出狗：先草稿，再细化，最后精修" | L3-2 | 匹配 iterative，改 subject="狗" |
| L1-3 | "生成一套炫酷表情包：酷、爱、胜利、加油4种" | L3-3 | 匹配 radiate，改 items |

## L2: 微调变体

Agent 应匹配类似模板并调整参数。

| # | 指令 | 变体点 | 通过标准 |
|---|------|--------|---------|
| L2-1 | "生成6张不同风格的猫" | L3-1 改步骤数 | 匹配后调整 steps 数量 |
| L2-2 | "一步步画出猫：草稿→勾线→上色→细节→精修" | L3-2 改步骤数 | 匹配后改5步 |
| L2-3 | "生成一套6种动物表情包" | L3-3 改 items | 匹配后 6 items |

## 执行顺序

L3 → L1 → L2（L3 产出模板，L1 复用，L2 验证灵活性）
