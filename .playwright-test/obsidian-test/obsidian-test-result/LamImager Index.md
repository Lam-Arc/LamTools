## 项目本质

LamImager 是一个全栈桌面应用（Python 3.14 / FastAPI / Vue3 / LangGraph / SQLite），支持 AI 驱动图像生成、对话式界面、LLM 规划与实时流式输出。它属于 [[LamTools 生态设计]]中的图像/视觉成员。
