关于 Lam

一个热爱 Minecraft 和编程的开发者，用代码在方块世界中创造无限可能。

L

你好，我是 Lam

我是一名资深的 Minecraft 玩家和 Mod 开发者。从第一次踏入方块世界开始， 我就被这个充满无限可能的游戏深深吸引。随着对游戏理解的深入， 我开始尝试用代码来实现自己的创意，逐渐走上了 Mod 开发的道路。

对我来说，Mod 开发不仅仅是一项技术工作，更是一种艺术创作。 每一个 Mod 都承载着我对游戏的热爱和对玩家体验的思考。 我希望通过我的作品，让更多人感受到 Minecraft 的魅力。

Java Kotlin Forge Fabric Mixin Gradle Git OpenGL

开发历程

一步步走来的足迹

2019 年
初识 Mod 开发
第一次接触 Minecraft Forge，学习 Java 编程，开始尝试制作简单的 Mod。 虽然最初的尝试很稚嫩，但点燃了我对 Mod 开发的热情。
2020 年
首个公开发布的 Mod
经过一年的学习和积累，发布了第一个正式版本的 Mod， 获得了第一批用户的认可和宝贵的反馈意见。
2021 年
技术栈升级
学习了 Kotlin 语言和 Fabric 框架，开始尝试更现代化的开发方式， 作品质量得到显著提升。
2022 年
社区合作
开始与其他 Mod 开发者合作，参与开源项目， 在社区中建立了良好的口碑和影响力。
2023 - 至今
持续创新
持续推出新的 Mod 作品，不断优化现有项目， 致力于为玩家带来更好的游戏体验。
