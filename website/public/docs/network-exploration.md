# Sunday 网络拓展

Network Exploration 是 Sunday 的 Windows 桌面内置网络插件，将网络状态、代理、下载、连接查询和诊断放在同一个界面。

从左竖栏打开完整网络界面；右键入口可以分屏；右侧快捷面板可以查看当前状态并运行快速诊断。多个界面共用一个后台，关闭页面不会终止下载。

## 无需另外安装内核

Mihomo 与 aria2 随插件提供。使用代理或下载时自动准备并启动经过校验的内核，不弹出第三方管理窗口。

不使用代理也能查看网速、接口、DNS、进程连接及端口，运行 DNS/TCP/HTTPS、Ping 或路由诊断。

## 代理与下载

导入 Mihomo YAML 或 HTTPS 订阅后，可以查看节点和代理组、测试延迟、选择节点，以及切换直连、规则与全局模式。默认只开放本机混合代理端口 `127.0.0.1:17890`，不会自动设置系统代理或启用 TUN。

下载支持 HTTP/HTTPS、分段、暂停与继续、队列、任务优先级、限速和 SHA-256。应用重启后，未完成的任务恢复为暂停状态，继续时使用已有文件。取消下载保留已经写入的文件。

## 系统配置与恢复

当前支持经确认后修改指定接口 DNS、当前用户系统代理、应用出站防火墙规则及应用发送限速。操作前保存加密快照，恢复前检查当前设置是否仍属于插件，避免覆盖用户或其他软件的修改。

需要管理员权限的功能由 Windows 检查权限。插件不会永久提权，不安装 HTTPS 根证书，不上传网络活动记录。订阅和下载凭据使用当前 Windows 账户加密保存。

## 当前范围

这是基础版本。浏览器接管、上传与跨设备同步、TUN、高级网站加速、WFP、应用级字节统计、多源下载和自动修复仍在后续开发范围。系统接口流量和代理流量分别解释；诊断不会将推测当成已经证实的原因。

本功能源代码及内核信息见 [项目仓库](https://github.com/Lam-Arc/LamTools)。内核分别遵循 [aria2](https://github.com/aria2/aria2/tree/release-1.37.0) 与 [Mihomo](https://github.com/MetaCubeX/mihomo/tree/v1.19.33) 的许可证；分发版本附带其许可证。
