# LamTools Pet Packs

桌宠资源目录是 `.lam/core/pets/`。内置 Pet 会在首次启动时复制到这里；同名资源不会被覆盖。你可以把自定义 Pet Pack 文件夹放到这个目录，再在 Pet 设置里点“刷新资源”，或重启 LamTools。

## 目录结构

每个 Pet Pack 都必须包含以下内容：

```text
my-pet/
├─ pet.json
├─ idle/0000.png
├─ running/0000.png
├─ waiting/0000.png
└─ error/0000.png
```

四个状态目录都必须存在，并且至少包含一帧 PNG 或 WebP 图片。文件名按自然顺序播放，例如 `0001.png`、`0002.png`。每个状态最多 240 帧，FPS 必须在 1～60 之间。

状态含义是：`idle` 表示没有任务，`running` 表示有 Agent 正在运行，`waiting` 表示需要你处理审批或回答，`error` 表示有任务刚刚失败。建议图片使用透明背景、约 192×208 像素，并让角色主体在各状态中保持相近的画布位置；实际窗口会按比例缩放。

## pet.json

最小清单如下：

```json
{
  "schemaVersion": 1,
  "id": "my-pet",
  "name": "我的桌宠",
  "states": {
    "idle": { "fps": 8 },
    "running": { "fps": 12 },
    "waiting": { "fps": 10 },
    "error": { "fps": 8 }
  }
}
```

`id` 必须与文件夹名称一致，只能使用字母、数字、点、下划线和连字符；`name` 是设置界面显示的名称。图片必须是真实可解码的 PNG/WebP，建议使用带透明背景的正方形或接近正方形素材。当前 Pet 窗口按比例缩放，不需要把图片预先放大到窗口尺寸。

可以复制 `template/` 作为起点。无效资源会在设置里标记为“无效”，不会被选中；如果当前选中的资源变坏，LamTools 会自动退回到可用的内置 Pet。

常见错误包括：`pet.json` 的 `id` 与文件夹名不一致、缺少某个状态目录、FPS 超出范围、图片扩展名与实际格式不符、图片损坏。设置页刷新资源后会显示具体错误，修正文件后再次刷新即可。

当前 Phase 1 只支持序列帧 Pet，不支持 Live2D、插件市场、云同步或 AI 生成资源。
