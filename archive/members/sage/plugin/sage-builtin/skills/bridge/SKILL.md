# Bridge

Turn a surprising analogy into a falsifiable connection hypothesis before treating it as useful knowledge.

## Workflow

1. State the current problem, source domain, target domain, proposed mechanism, transfer conditions, and observable implications.
2. Use Explore to collect evidence from both domains, including primary sources, failed transfers, and counterexamples.
3. Use Verify to test whether the mechanism—not surface resemblance—supports the connection. Compare alternative explanations and boundary conditions.
4. Write the relation to the Map as `hypothesis` until the evidence satisfies the declared verification standard. Preserve evidence and conflicts under `TRACE_MAP_CONTRACT.md`.
5. Recommend the bridge only when it changes a decision, experiment, search direction, or explanation. State the cheapest test that could disprove it.

When delegated, require a structured evidence package or an artifact path. A Sub-agent's creative summary alone is a lead, not verified support.
