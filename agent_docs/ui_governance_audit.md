## 有意保留的不同

- `ThinkingIntensitySlider.vue` 是纵向、带等级色、刻度和专用动效的思考强度控件；`SundayRange.vue` 是通用数值范围控件。二者语义与交互不同，保留独立组件，展厅均可操作。
- `CoreSendStopButton.vue` 位于输入区，带发送、停止与长按终止行为，且使用输入区反色；不与普通按钮机械合并。
- 复选框用于多项选择或表单布尔值，开关用于立即生效的设置。二者保留不同语义，不因外形相近直接互换。
- 工作流切换确认提供取消、放弃、保存并切换三种选择；队列清理确认嵌在面板内。它们不同于资料库的两项操作遮罩，不机械替换。资料库创建和重命名对话框包含输入与异步错误，使用 `LibraryNameDialog` 共享表单，保留业务校验、提交和错误处理；`design-system-library-name-integration.test.ts` 覆盖两个页面的创建与失败回退。
- 组件所属区域决定主题色：例如侧栏复选框引用 backdrop 文字色，主内容区引用 main 文字色，填充则使用 control 反色配对。

## 已核实的检查结果

2026-11-15 自动检查报告 29 项（175 个文件），最初为 37 项；以下不能仅凭数值判为重复：

- `AttachmentTray.vue` 的 64% 是图片上的深色操作背景，需保持图像上操作的对比度；不能机械换成普通控件的 8%。

- 侧栏原生滚动条被隐藏，是为了配合可拖动的独立侧栏滚动条；横向工具栏隐藏滚动条以保留紧凑布局。聊天区的 5% 滚动条透明度与全局 18% 不一致，尚需根据实际视觉及可操作性核对。
