# UI 治理盘点与迁移记录

浮层开合、设置与消息入场、聊天与侧栏等待旋转已接入共享样式。展厅新增「动效」，把上述三类动作与真实发送键、模型菜单和工作流反馈等集中提供。减少动效时仍保留等待文本、可用操作和焦点行为；模拟开关仅作用于展厅的共享 CSS 动效。


「页面与组合」的生产界面共用标题、内容面板、筛选和错误提示。项目设置合为分区式表单，调用台、插件、定时任务与设备页减少各自的卡片配方。资料库、搜索和定时任务复用筛选的选中样式。真实输入栏加强聚焦边缘，工作流队列用共享的操作语义。展厅仅用来验证这些实际页面。


参考随附 Material Playground 的材质层次，正常用户和助手气泡用共享阅读玻璃并以主题淡粉、淡蓝区分；纯正文、消息编辑和待接手引导保留各自状态。模型菜单底板、分组菜单与悬浮思考条复用同一玻璃，组／供应商切换使用实色。面板、菜单和阅读是同一材质的三个变体。浏览器验证浅暗主题、消息折叠、助手气泡开关及模型分组操作；展厅分类随实际展项生成。

## 范围与权威来源

- 桌面应用及窗口入口：`core/ui/src`、`core/desktop/src` 和桌面 HTML 入口。移动端按项目规则排除。
- 插件：仅包括随 Sunday 分发并嵌入应用的随附插件界面。插件可能独立加载，不能假设都继承宿主 CSS；逐项检查入口和运行方式。

设计约束以 `.agents/skills/lam-design-spec/SKILL.md` 为准，运行时 token 以 `core/ui/src/styles/variables.css` 和 `core/ui/src/helpers/theme.ts` 为准。

设置、插件、搜索、连接和项目页面原各自复制同一主题映射；现共用 `settingsThemeVars`，保留浅色覆盖、渐变首色和缺省主题行为。`design-system-settings-theme-vars.test.ts` 与 `design-system-settings-theme-pages.test.ts` 覆盖颜色映射与五个页面的主题切换，展厅使用同一函数。

## 已核实的组件与迁移

资料、记忆和方案页面均已接入隔离数据展厅。资料展厅的上传、打开、复制、收藏、归档和移除使用内存模拟，真实页面上传、收藏和移除有交互测试，浏览器验证复制不会触碰系统剪贴板。记忆和方案展厅可在内存中新增、编辑、移动、重命名和删除；真实页面创建目录与文件及模拟数据操作有测试，不接触项目文件。记忆与方案卡片的内部菜单回车不再冒泡触发打开，网格及列表均有组件测试；真实浏览器验证深浅主题下菜单可打开，展厅复用应用的菜单承载器。上述证据不代表这些页面所有编辑及文件操作均已覆盖。

真实工作流画布已接入展厅，复制粘贴限定于画布内存；浏览器验证网格切换、节点拖拽与位置同步、连线删除及拖动重建、节点复制、运行锁定及容器删除警告。修复状态或选中变化误触位置同步造成的循环更新，让删除确认显示不可撤销警告及内部元素数量，并阻止运行锁定期间通过粘贴、编辑或删除修改画布。完整工作流切换仍需单独验证。

真实分屏工作区及文本编辑器已接入展厅，示例控制器和文档只在内存中运行；浏览器验证标签新增、切换、关闭和跨分屏拖动，分隔线键盘调整，鼠标选择布局子菜单及辅助屏合并，并检查真实编辑器草稿保留、关闭确认和模拟保存。真实文件预览也接入展厅，以隔离数据验证 Markdown、文本、图片缩放、读取失败重试及模拟打开。真实分屏浏览器可用隔离服务预览地址校验、导航和失败；原生事件监听及外部打开失败有明确提示。其他文件格式、实际文件、原生网页和插件内容加载仍需单独核对。

共享菜单自身滚动原被全局滚动监听误认为页面滚动，导致子菜单在鼠标操作时关闭；现保留菜单内滚动时的浮层，页面滚动仍关闭。真实分屏菜单及独立菜单展厅均有浏览器测试。

分屏浏览器现在等待事件监听就绪后再创建网页，关闭时不会重复清理，也不会用请求地址覆盖先到的重定向结果；监听失败和外部打开失败均可见。隔离服务测试覆盖这些异步顺序，原生网页实际运行仍需桌面环境验证。

分屏文件树原有树语义但缺少方向键导航；现支持逐项移动、展开／收起、跳到首尾及单一 Tab 入口。切换项目会清理旧目录并丢弃迟到结果，读取失败可重试原目录。真实组件以隔离目录接入展厅，浏览器及组件测试覆盖焦点、目录、文件打开、失败重试和项目切换；实际文件系统权限仍依赖桌面环境验证。

真实输入编辑器与输入栏组合已接入展厅，使用本地示例建议和发送动作；浏览器测试覆盖文件／上下文补全、补全回车不误发送和发送后清空。共享建议菜单改为只滚动当前实例，避免主窗口与分屏互相干扰，上下文建议读屏标识由 `@` 修正为 `#`；组件测试覆盖多实例及标识。展厅禁止引用右键菜单以避免触及真实剪贴板或文件；应用的完整会话、上传与命令流程仍需单独核对。

真实待发送队列已接入展厅，示例编辑、取消、拖动排序和引导均在内存完成。队列操作获得键盘焦点时隐藏装饰省略号，避免遮挡操作按钮；省略号改为非交互装饰，浏览器验证焦点、禁用、编辑和排序。

输入区真实模型、思考强度、权限及工作环境组合已接入展厅，示例选择只改变内存。权限、模型和环境菜单在控件被禁用后立即关闭并拒绝更新；环境列表清空也会关闭，方向键和首尾键可导航，Escape 返回焦点。组件与浏览器测试覆盖禁用、键盘和本地选择，动画完成后才将焦点移入可见选项。
