## 不算过度设计的部分

公平讲，这几处复杂度是有理由的：

- **Python → Rust 渐进迁移**本身不冗余。真问题是并行跑了两套 Rust，不是「要不要迁移」。
- **插件权限 / 沙箱 / 信任模型**：插件能读密钥、能开窗口，不做隔离才是错的。
- **事件投影、RPC 边界、子代理通道**：这些是为「流式 + 可回退 + 多代理」付的合理代价。
- **46 个前端功能目录**：功能确实有那么多，压缩它会变成假抽象。

## 一句判据

判断过度设计的标准不是「模块多不多」，是**「同一个决定你做了几次」**。上面三个决定都被做了 3 次：运行时 3 次、快照 3 次、宿主 4 次。
