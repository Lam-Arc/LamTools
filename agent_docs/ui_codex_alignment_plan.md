# 整体界面对齐 Codex 桌面版 — 对齐方案（待逐块确认）

> 目标：把 Sunday 桌面版的整体界面，对齐到用户提供的 Codex 桌面版截图标准。
> 原则：只对齐布局、层级与观感；不另起配色体系，不引入 Codex 的产品功能（升级、账号体系等除外）。
> 状态：**方案待确认** — 逐块确认后才实施；每块独立交付、独立验收。

## 区块划分与对齐动作

### 1. 首屏（空会话开始页）
- Codex 标准：居中云形图标 + 一句大字问句；输入栏悬浮于底部中央。
- Sunday 现状：开始页已存在，但构图平淡，输入栏与正文挤在一起。
- 对齐动作：首屏改为大字问候/问句 + 标志图形；输入栏独立悬浮在底部中央，占位文案与呼吸感对齐 Codex。
- 影响面：仅开始页自身；会话进行中的界面不动。
- 工作量：小。

### 2. 输入栏（composer）
- Codex 标准：三段式 —— 上沿一行项目名小签；中部大输入区；底部一行动作：左侧「＋」与权限徽标（醒目色），右侧模型选择、语音键、圆形发送键。
- Sunday 现状：控件齐全（项目、权限、模型、深度思考、发送），但排布与 Codex 不同。
- 对齐动作：重排为 Codex 的三段式；「＋」收拢附件类动作；权限徽标用醒目色放在左下；发送键改圆形。能力不增不减。
- 影响面：所有会话界面（含插件内嵌的输入场合视情况跟随）。
- 工作量：中。

### 3. 侧栏（会话列表栏）重组
- Codex 标准：顶部产品名下拉 + 铃铛 + 搜索；「新聊天」按钮；分组依次为「置顶（含文件夹/项目嵌套）」「项目（可展开）」「最近」，每组可「展开显示」；会话行悬停浮出操作。
- Sunday 现状：「新建项目」在顶；会话按项目分组；无置顶、无最近分组；操作入口较少。
- 对齐动作：
  - 顶部改为「Sunday ▾」工作区下拉（保留搜索入口；铃铛可先做占位）。
  - 「新聊天」= 新建会话。
  - 新增「置顶」分组与会话置顶能力（新能力：需要存储与同步，手机端同步跟进）。
  - 项目组与最近组的展开/收起与「展开显示」。
  - 会话行悬停菜单：置顶 / 重命名 / 删除。
- 影响面：侧栏全部；置顶为新增能力（桌面 + 手机 + 命令行三端对齐）。
- 工作量：中大（置顶能力是主要增量）。

### 4. 最左图标竖栏（rail）
- Codex 标准：一条独立窄竖栏：主页、历史、资料库、浏览、更多等，底部下载与头像（带未读角标）。
- Sunday 现状：这些入口排在侧栏内部顶部，账号在侧栏底部。
- 对齐动作：新增最左窄竖栏承载：主页、定时任务、资料库、插件、搜索、设置；底部账号头像。原侧栏顶部图标排收掉，侧栏变成纯会话列表栏。
- 影响面：壳层布局（桌面）；手机端不引入双栏，维持现状。
- 工作量：中。

### 5. 窗口框架：自绘顶栏 + 程序菜单
- Codex 标准：无边框窗口；顶栏一行：返回/前进、「文件/编辑/视图/帮助」程序菜单、右侧窗口控制键。
- Sunday 现状：系统默认标题栏。
- 对齐动作：去系统边框，自绘顶栏（返回/前进、程序菜单、拖拽区、窗口控制键）；菜单带中文项与快捷键（新建聊天 Ctrl+N、搜索 Ctrl+K 等挂在菜单上）。
- 影响面：唯一动到窗口层的一块。Windows 的拖拽、双击最大化、贴边分屏、多屏 DPI 等系统行为需要逐项验收；安装包需要回归。
- 工作量：大，建议单独立项最后做。

### 6. 观感校准（贯穿）
- 在现有主题体系内收紧：分隔线更淡、卡片描边减少、悬停更轻、留白向 Codex 靠。
- 不新建配色；浅色预设同步校准。

## 交付顺序（每步独立可验收）

1. **第一批**：首屏大问句 + 输入栏重排（可见度最高、不动结构）。
2. **第二批**：侧栏重组（置顶 / 最近 / 展开显示 / 工作区下拉 + 悬停菜单）。
3. **第三批**：最左图标竖栏。
4. **第四批**：窗口框架（自绘顶栏 + 程序菜单 + 安装包回归）。

## 需要拍板的点

- 置顶能力三端对齐（桌面 / 手机 / 命令行）是否随第二批一起做（建议是）。
- 程序菜单的具体菜单项清单（第四批前给一版清单确认）。
- 铃铛/通知是否只做占位（建议先占位，通知能力另行立项）。

## 验收方式

- 每批完成后在 Sunday 窗口对照 Codex 截图逐项核对，截图留档。
- 全量测试保持绿色；涉及窗口框架的一批额外做安装包安装验收。
