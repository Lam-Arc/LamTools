## 总体方案（请核对）

**一句话**：一条 67.2 秒 / 1920×1080 / 60fps 的宣传片；三段从左到右——代码 → 办公 → 游戏；画面全部由产品自己的界面（真实 `core/ui` 在无头浏览器里逐帧渲染）与真实产物（真实源码、真实 11 页复盘、真实游戏 450 帧）构成；音乐为代码合成的 100 BPM，与画面共用同一张节拍表。

**结构**

| 时间 | 内容 |
|---|---|
| 0–2.4s | 开场三块依次落定，各自亮出真实产物（源码在写 / 复盘页整页往下滚 / 游戏在跑） |
| 2.4–17.4s | 代码段：点第一块拓宽；产品界面跑"实现这个小游戏"的真实对话；左窄栏=源码页+工作目录文件树；右窄栏=产品"定时任务"那一屏 |
| 15.0–17.4s | 还原回开场三块并排（内容同时回来），再由三块变办公 |
| 17.4–36s | 办公段：左=资料库分层，中=真实对话，右=成果墙（两列错落、真循环、未生成处为"待生成"示意） |
| 30.4–36s | Agent 退场，成果墙接管整块台面 |
| 36–60s | 游戏段：左=产品自己的窗口（做这个小游戏的真实对话，1:1），右=真实游戏（整幅可见，随段落长大到贴框） |
| 60–67.2s | 游戏占满台面 → 收尾：名字落定、细线拉开、"一句话，到能用的东西" |

**机制**：真实前端渲染台；各段沿用开场那一击；成果墙格位不动、容器变宽、真循环；音乐与画面同表（段落重音落在 2.4/17.4/36.0s，开场第一记 0.6s 与三块落定同拍）；审片走 3fps 九格图 + 无上下文独立审片人。

1. 游戏段左半 = 产品自己的窗口（对话 + 真实源码），子代理那一层也由产品界面承载。若你要的是产品里那个**子代理面板/列表**本身入画，我再渲染那一个界面进来（多一轮）。
