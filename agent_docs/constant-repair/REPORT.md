## 整理、方案及落实

| 类别 | 证据与影响 | 方案及当前落实 |
|---|---|---|
| 数据库压力与连接等待 | 主要错误簇，影响会话列表、历史、目标、子代理、回合持久化、后台恢复与通知；旧 4+4 池和新 8+8 池均出现过 | 保留已有读写分池，减少实时通知的大字段读取；后台被动检查点改为独立短连接，不再等业务池；解决下行所述重复巡检根因。没有盲目扩大连接池，也没有声称所有负载下都不会再饱和 |
| 终态记录跨会话冲突 | 同一调度执行编号在两个会话复用，事件主键却只含执行编号；查询实际活动库的单个目标确认，结束事件属于另一个会话。反复巡检 **49,299 次**仍未结束目标会话 | 终态幂等键包含会话、逻辑回合、执行代次与原因，固定 64 字符摘要；事件存储拒绝把其他会话记录作为本次写入结果。双会话真实临时库测试已复现并验证修复，重复巡检为零 |
