底座自带六十八项测试，覆盖注册表一致性、文档校验、迁移、编译产物、注入与草稿发布、对齐分布、拖动吸附、实例覆盖与工作台操作。

工作台是浮动三栏：左侧图层树列出全部已登记元素，中间直接预览真实界面并框出选中元素，右侧按登记权限给出颜色、背景、透明度、圆角、间距、字号、层级与显示开关。编辑走独立的预览样式通道，不影响已发布主题；发布会写正式样式并落到本地存储；支持撤销重做、恢复默认与 JSON 导入导出。入口在设置 → 界面 → 编辑布局。

工作台还支持拖动选中元素：位移用独立的 translate 表达，叠加在组件原有 transform 之上，不参与布局流；拖动时按父容器与视口的左中右、上中下六条边吸附，命中阈值显示参考线，松手才提交；方向键微调一像素，按住 Shift 十像素。

背景素材支持上传、按内容哈希去重、比例读取与内嵌存储；适配方式有 cover、contain、stretch、tile，溢出单独开关，不误用裁切。单张上限约 1.5MB，超出给出提示。

九宫格切片按四边像素编译成 border-image，拉伸时四角不糊、边缘不重复压缩。

实例级覆盖补上了「只改这一条」：消息行与会话行的根节点各自带实例编号，点中哪一条就把改动写到哪一条，模板一律不动。编译时实例规则排在模板规则之后，两者权重相同，所以实例压过模板；断点规则再排在实例之后，窄屏依旧优先。校验要求实例必须指向已登记模板，并按该模板的可编辑属性逐项检查，指错模板或越权改属性都会拒绝发布。编辑面板在实例作用域下显示它从模板继承来的值，第一次改动才落到这一条上，清除时只删这一条，不碰模板。切回普通元素或普通模板时自动退出实例作用域，避免改动写到看不见的地方。

多选对齐与分布、拖动吸附、九宫格与实例覆盖都补了独立测试，工作台行为测试覆盖了点实例、改颜色、清除、切回基础样式与退出多选五种路径。

断点覆盖：属性面板可以在当前窗口宽度处加一个断点，之后所有修改写进这个断点；编辑断点时会把它合进基础样式做强制预览，能看到窄屏效果；发布后编译成媒体查询。断点可删除。

模板同步：消息行与会话行登记为模板，改一次作用于全部同类节点，编译成模板选择器。顺带修掉一个隐患：消息根节点原来用唯一标识，但页面上有几十条消息，唯一标识实际只指向第一条，现在改为模板身份。

多选与对齐：按住 Ctrl 或 Cmd 点选可加选，画布上出现多个选框，工具条提供左中右、上中下六种对齐与水平、垂直分布；对齐按整体包围盒计算，分布只挪中间元素、首尾不动。对齐结果写成位移，与拖拽共用同一套提交逻辑。

拖动时显示与父容器四边的实时距离，松手才提交。

背景九宫格：素材可以选 nineSlice，按上右下左四边切片编译成边框图，中区填充，切片数值可调。

素材预解码：导入时读取真实尺寸并解码，启动时对已保存素材异步预解码，失败只影响该素材，不阻断界面。

安全出口：Ctrl+Alt+Shift+R 清除编辑器发布的主题并重载，不依赖能否进入设置页。

工作台的测试覆盖列表完整性、预览通道、发布落盘、恢复默认，加上吸附计算的五条断言。编辑器内的输入框与下拉同样走输入区令牌，和全站一致。

## 六、需要决策或实机确认的点

1. 触屏多选采用横向拖动进入选择，竖向仍是滚动。若要竖向拖选，必须放弃触屏滚动，需要定。
2. 目录卡片按左栏底边对齐，与输入栏的间距只在单元测试环境验证过，需要桌面端实跑一次看。
3. 图片预览缩放按宽度百分比，不按原始像素 100%。若要求「原图字号」需要再加一层尺寸探测。
4. 自动拆分目前只有客户端解析与结构兜底。要让模型主动输出拆分标记，需要后端在系统提示词里加一段轻量指令，并在落库前剥掉标记。
5. 消息气泡的显示名称与头像保存在 `core.assistantDisplay` 命名空间，后端通用分支可直接存，是否需要白名单校验待定。
