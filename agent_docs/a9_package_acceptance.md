## 发现并修复的问题

1. 插件资源返回过程中把 Starlette 响应头当作普通 dict 调用 `pop`，导致实际资源请求 500。已修复并新增真实应用路由验收。
2. 打包页的 CSP 含 nonce；插件插入的无 nonce 样式被浏览器拦截，导致网络拓展和刷B站仅剩无布局内容。宿主新增 `context.addStyle`，按所属文档携带 nonce、按实例清理；网络插件接入，原版 bili 前端通过局部文档适配携带 nonce。没有放宽 CSP。
3. 之前重画的 bili 页面不符合用户的直接移植要求。现保留上游 2.2.2 的 `client.js` 原文件，静态打包 React 18.3.1/ReactDOM，完整运行原版组件、CSS、开关、四页签、扫码与视频墙。适配层只连接注册、宿主操作、主题别名和清理；封面仍经宿主读取。
4. 原版封面接口返回 HTTP CDN 地址，适配层先校验域名再升级 HTTPS，实际封面读取通过。
5. `port-plugin` 原来的“只取能力、不取代码”、UI 优先替换成声明式块及“复制代码答案应为 no”等规则已纠正。`create-plugin` 增加复刻/移植入口。优先复用许可允许的源码、组件、样式和资源；必要改写必须列出具体兼容性证据。两份 Skill 校验通过，安装包内的版本与工作区一致。
