# UI 治理执行清单

原始目标：全面盘点现有前端；统一 tokens 与可复用组件，保留必要差异；建立能操作真实组件的展厅；迁移存量并验证无退化；建立可检索的复用规范。仅桌面端，优先现有资产；不使用电脑操作验证。

1. [进行中] 盘点 `core/ui` 与实际随桌面交付的插件界面，记录组件、调用位置、样式、布局、动效和交互，区分有意差异和待合并项。验收：范围可追溯，重复点有调用方和迁移依据。
2. [进行中] 确认 tokens 和共享控件的权威来源，针对实际重复先写行为验收测试，再渐进合并。验收：主题、操作、状态、可访问性保持正确，删除废弃实现。
3. [进行中] 扩展展厅，覆盖可复用组件的真实预览、搜索、分类、筛选、参数、变体、交互和源码定位。验收：每个登记项可实际操作，差异与依赖明确。
4. [进行中] 按调用位置迁移存量界面，保留专用行为和必要差异。验收：新增针对性测试覆盖关键状态和行为，检查主题和样式回归。
5. [进行中] 完善组件目录、选用规范及 Agent 检索入口。验收：文档反映实际实现，可持续更新而非复制另一套规范。

已验证：展厅五十八个控件、样式或令牌可交互或对照，搜索、分类、主题、滑条、下拉与输入框参数、确认弹窗及源码查看测试通过；展厅可检索 Sunday Vue 源码文件并标示预览覆盖；已生成桌面与随附插件的源码索引（不等于逐项审查）；共享按钮在深浅主题与设置区的颜色、主次区分和减少动态效果由真实浏览器测试覆盖；共享下拉的键盘选择和焦点恢复由新增测试覆盖；插件管理与内置网络工具的开关已合并至 SundaySwitch，忙碌提示、禁用条件及失败回退由新增测试覆盖；插件配置、工具选择、桌宠设置与工作流工具列表采用共享原生复选框，新增测试覆盖提交及选择。工作流运行策略、参数、输入与触发器也接入共享复选框；成果多选、模型分组、任务权限、侧栏布局、插件动作、桌宠导入预览使用共享复选框；无静态调用方的 Ping 工作台和桌宠动作编辑源码也已接入，插件进度使用共享进度条；无静态调用方的桌宠动作编辑组件中的行为滑条，以及无静态调用方的 Ping 工作台六处下拉、桌宠导入预览动作下拉、网络工具全部原生下拉，以及主题编辑器的显隐、溢出、两类透明度及其所有下拉使用共享控件，主设置与独立桌宠窗口的下拉复用 UiSelect 并共享遮挡、精度选项。新增测试覆盖提交、禁用、选择及进度值。工作流类型检查尚被现存桌宠类型和旧实验页错误阻挡。仍需覆盖其余实际使用场景。详细目录见 `agent_docs/ui_component_catalog.md`。
