## 0. 执行摘要与边界

实现 `设置 → 主题 → 编辑布局` 的可视化主题编辑器：用户以 PPT/PS 式操作修改组件位置、尺寸、边缘、层级、行高、颜色、渐变、SVG/PNG 背景，具备磁吸、间距调整、图层树、模板实例、响应式适配和主题保存/恢复。编辑操作转化成稳定的**布局规则**，而不是把所有元素存成绝对坐标。桌面端具备完整编辑能力，Android 端应用同一主题的移动布局，不必实现完整的移动编辑器。[确认]

本次还要修复现有 UI：聊天区域自动扩宽；文件点击后自动打开分屏/预览标签；统一返回按钮；修复被遮挡的弹出菜单；自适应图片；让分屏入口更容易发现。[确认]

**明确不做**：Agent 心跳、定时任务、Computer Use、人格提示词调整；未被明确指定的其他现有可拖拽面板改造。[确认]

**工程底线**：不更改业务逻辑、不破坏既有项目与会话数据、不让未保存草稿影响运行主题、主题损坏时仍可恢复。插件 UI 可通过受控注册机制接入，但不允许任意 DOM/CSS/脚本注入。

## 1. 总体目标与验收原则

### 1.1 用户体验目标

1. 用户选择组件后能看出：选中了谁、父级是谁、修改会影响谁。
2. 用户只需拖动、吸附、滚轮和输入数字，就能控制位置、大小、间距；高级设置可折叠。
3. 列表中修改同级间距自动同步，不需要逐项修改；修改模板统一影响同类型组件。[确认]
4. 画布从宽屏拖到窄屏时，组件应伸缩、重排或切换断点，而不是被强制扁拉。
5. PNG/SVG 背景可等比、非等比、裁切、九宫格等方式渲染，并可选择在组件外溢出。[确认]
6. 编辑器的框线、锚点、虚线、标注只在编辑时存在，不影响正常应用。[确认]

### 1.2 成功标准

- 在空白布局、新会话、长标题、侧边栏折叠、文件预览、窄窗口、主题损坏等状态下稳定工作。
- 同一个主题在重启后视觉一致；断点切换与返回导航可靠。
- 关键交互可通过键盘或数值面板完成；主题不能让恢复入口永久失效。
- 性能有可测量的预算和降级策略，不因复杂主题使正常运行必须加载编辑器。

## 2. 全局架构

### 2.1 五个边界清晰的模块

1. **Component Registry（可编辑组件注册表）**：由 Sunday 内置界面及插件声明可编辑节点、语义 ID、父级、可修改字段、默认约束、预览态和保护级别。严禁从任意 DOM 推断全部可编辑能力。
2. **Theme Schema & Store（主题模型）**：设计令牌、组件预设、页面布局、模板、实例覆盖、断点、素材清单、草稿/发布版本。
3. **Layout Adapter（布局适配与验证）**：把声明式规则映射到现有技术栈的 Grid/Flex/定位方式，检查无效约束及响应式溢出。**不要从零开发通用 CSS 布局引擎**。
4. **Editor UI（独立加载）**：画布、选择命中、吸附、辅助标注、图层树、属性面板、历史记录。
5. **Runtime Theme Renderer / Overlay Host（运行时渲染和浮层宿主）**：只加载已发布配置和必要素材；跨容器装饰、菜单、弹窗分开治理。

### 2.2 集成策略

[适配时确定] Codex 必须先扫描现有仓库，识别框架（Vue/React/原生等）、组件体系、状态管理、路由、桌面壳与 Android 端实现、主题样式管线、插件注册方式及测试命令。沿用现有技术，不得为此需求盲目重写整套 UI。对无法注册的第三方黑盒控件，允许仅开放安全的容器级外观配置并在 UI 标注不可编辑字段。

**依赖方向**：运行端依赖 Theme Schema，不依赖 Editor；Editor 依赖 Registry 和 Theme Store，不直接篡改业务状态；浮层系统由运行端统一管理。编辑器内实时预览宜使用真实组件的只读/模拟数据沙盒。

### 2.3 主题优先级与覆盖

按属性合并，而非整对象粗暴替换：

`Sunday 安全默认值 < 全局令牌 < 组件模板/预设 < 页面布局 < 页面实例覆盖 < 当前断点覆盖`。

交互状态（hover/pressed/focus/selected/disabled）是同一节点的状态化样式，在已选定作用域内应用，不与页面结构覆盖混淆。未声明的字段继承上级。

## 3. 编辑器工作台与操作

### 3.1 工作台构成

- 顶部：返回、主题名称、当前页面、撤销/重做、选择工具、吸附开关、画布缩放、宽度预览、辅助标注、预览、保存草稿、发布主题。
- 左栏：页面选择 + 图层树 + 搜索、折叠、锁定、独显、排序。
- 中央：所见即所得的可变尺寸画布；支持平移/缩放、容器边界、磁吸预览、响应式变化预览。
- 右栏：**布局 / 尺寸 / 约束 / 外观 / 背景 / 文字 / 响应式 / 状态 / 高级**；属性只展示注册表允许编辑的字段。
- 状态栏：当前选中对象、父级、修改作用域、活跃断点、是否有未保存修改、警告数。

### 3.2 编辑与预览严格分离

编辑态不直接执行发送、删除会话、授权、文件写入等业务动作。预览态恢复交互外观，但对于危险业务操作继续使用模拟响应或无副作用 mock；必要时使用独立 preview session，不能动真实用户数据。编辑器必须保留始终可访问的退出入口。

### 3.3 选择、颜色与层级识别 [确认]

- **蓝色实线**：当前选中的单个组件实例。
- **青绿色轮廓**：选中的布局父容器/列表容器；显示其受控布局范围。
- **紫色实线 + 关联实例紫色虚线**：进入共享模板编辑；实线为当前样本，虚线为同模板其他实例。
- 悬停时仅细框提示；只在尺寸可调时显示缩放手柄。
- 单击实例；双击进入子级/隔离编辑；`Esc` 退出一层或取消选择；图层树可以直接定位精确层级。
- 选择与修改范围分开：右侧明确显示 **「修改：共享模板 / 仅此实例」**；在涉及多对象同步前给出清晰反馈。

### 3.4 父子关系提示 [确认]

- **仅选中子组件时**，在子组件中心与其**直接父组件中心**之间绘制一条细虚线，端点和父容器轮廓可轻量高亮。默认不展示整个祖先链。
- 虚线是关系提示，不是约束线/拖动手柄，不响应鼠标事件，不影响实际布局。
- 中心几乎重合时改用短折线或「父级：xxx」小标识，防止退化为不可见的点。
- 普通移动不默认改变父级。只有目标容器出现明确的接收高亮、用户释放确认，或在图层树进行重挂载，才改变 parent；失败时回滚。
- 重挂载时转换坐标与约束到新父容器语义坐标，确保视觉尽量原位，并验证循环和非法嵌套。

### 3.5 多选、隔离与快捷操作

支持框选、多选、组合/解组、对齐分布、复制粘贴、删除、锁定、隐藏、独显、撤销重做、键盘微调、数值输入。隔离模式使其他区域淡化和不可误选，但不改变运行时可见性。[推荐默认]

## 4. 尺寸、布局与规则存储

### 4.1 必须拆开的三件事

- **组件尺寸模式**决定元素多大。
- **布局约束/吸附关系**决定元素在哪、与谁相邻。
- **响应式规则**决定空间不足时何时改变结构。

三者在 Schema 中单独建模；不能混用一套通用 x/y/scale 参数。

### 4.2 容器类型

- `row` / `column`：自动布局，拥有 `gap`、对齐、内边距、换行策略和子项顺序。
- `grid`：列轨道/行轨道、跨行跨列、轨道最小最大值。
- `free`：用于悬浮和特殊装饰，采用有限锚点定位；默认不用于普通会话列表。
- `slot`：运行时结构固定的受保护占位容器，允许修改暴露的外观/间距，不允许断开业务绑定。

### 4.3 尺寸模式

宽、高各自有模式，支持：`fixed` 固定值、`hug` 内容适配、`fill` 填充剩余空间、`relative` 按父容器相对尺寸、`ratio` 等比、`stretch` 拉伸。配置最小值、最大值、可选宽高比；遵守文本内容的最小可用尺寸。按钮、图标默认固定；消息区默认 fill；图片默认 ratio；标签默认 hug。[推荐默认]

布局单位以逻辑 CSS px（或当前 UI 框架对应的逻辑单位）保存，不存屏幕物理像素；支持百分比、auto、设计令牌等明确类型。高 DPI/Android 按平台换算；缩放画布不改主题尺寸。

### 4.4 锚点与归属

每个节点有稳定 `nodeId`、`parentId`、`role`、`templateId?`。定位约束要明确引用对象的哪个边/角/中点/中心线，不能只存“相距某某 px”。

`free` 布局中允许：

- `anchor.target = parent | sibling | guide`；
- `anchor.edge = left | right | top | bottom | centerX | centerY | corner...`；
- `offset`、`align`、相对单位和可选保护边界；
- 单轴的尺寸与定位不能过约束；不允许环形依赖。

普通自动布局组中，相邻关系落地为父容器 `gap`、顺序与 `align`，**不是**为每个子节点创建互相依赖的 absolute 坐标。对于不能用组表达的特殊关系，创建明确的附加约束或参考线。

### 4.5 从拖拽推断意图

- 贴近父级边界 → 预览边界锚点；释放后保留该边距。
- 两节点边缘靠近 → 预览相邻关系；若在同一 auto-layout 组，修改顺序/父级 gap。
- 中心/边/文字基线对齐 → 建立对齐关系或设置父级对齐规则。
- 拖动跨容器时 → 默认不改父级，只有目标容器高亮可接收时才允许重挂载。
- 只经过吸附线不松手、或用户禁用吸附时 → 不保存关系。

若操作可能从 `free` 改为 `row` 等结构性变更，显示轻量确认与撤销能力，避免悄悄转换容器类型。

### 4.6 冲突优先级和故障处理

校验条件：循环父级、循环锚点、固定宽与双端固定锚矛盾、min>max、目标被删除、越过受保护 Slot、无法访问的核心控件、非法单位、互相覆盖的断点。

**优先保护**：应用可恢复性与业务关键功能 → 注册表硬约束 → 布局组结构 → 最小尺寸与素材按指定比例 → 弹性伸缩 → 可调整间距 → 触发重排/滚动。对无解的编辑不能偷偷选择某条规则，应拒绝提交并明确指出冲突对象、冲突规则及推荐修复选项。

## 5. 磁吸、标注与距离操作 [确认]

### 5.1 吸附几何对象

组件四边、四角、边缘中点、几何中心、水平/垂直对称轴、文字基线、父容器边界、用户参考线、自动布局组边界。候选可按距离、同级关系、语义优先级评分，多个目标重叠时允许 Tab 切换候选。[推荐默认]

### 5.2 调整间距

- 鼠标停在**外侧间距标记的稳定热区**并激活时：滚轮每格 ±1px，按 Shift 每格 ±8px；数值可配置。[确认]
- 双击标记直接输入数值；拖动标记可连续调整；支持属性面板直接输入。[确认]
- 未激活时滚轮继续用于画布/区域正常滚动，避免全局劫持。
- 自动布局列表：点任意同级项间的标记，实际编辑的是**父级列表 gap**，立刻同步所有相邻同级项。
- 定距锚点：点标记修改相应 `offset`，相同规则引用的对象按定义同步，不强制修改不相关兄弟节点。

### 5.3 极简三级标注 [确认]

- 间距充足：**朝上的横向大括号**，数值在外侧。
- 较小间距：简化为 **`>`**。
- 极小间距：只留**单段折线**。

不用复杂 CAD 延长线。标注根据**缩放后的可见尺寸**选择等级；标签始终在间距外面，自动放到组件上/下/侧方并避让其它标签。即便实际 gap 为 0–2px，点击热区和数字仍保持屏幕级最小尺寸，不能被 gap 裁切。不要过度依赖固定像素阈值；可用几何长度+测量文字宽度判断。标注图形与控制热区可以不重合，热点关联到唯一 constraint/gap ID。

### 5.4 独立编辑覆盖层

标注、关系虚线、参考线、边界框、对齐线由 Editor Overlay 绘制，位于独立、不受业务容器裁剪的层中，坐标从 DOM/组件布局矩形转换到画布屏幕坐标。画布缩放时坐标跟着变，标签字体与热区保持屏幕大小。辅助层有独立显示开关，默认只显示当前选中项相关标注；预览态全部消失。

## 6. 重复组件、主从列表与动态数据 [确认]

### 6.1 模板与实例

会话列表、项目树、文件列表、设置项等采用 `ListContainer → GroupTemplate → ItemTemplate → Runtime Instances` 的分层模型。

- 组的 `gap`、padding、排列规则管理同级间距；修改一处自动影响同组所有项。
- 会话项模板负责行高策略、文本行高、图标与文字间距、圆角、状态样式等；修改模板影响所有同类项。
- 具体实例可以显式覆盖属性；必须用稳定业务 ID 标识，禁止使用 DOM index 作为持久化实例键。
- 新建/删除/重排会话不应改变主题模板；被删除记录的实例覆盖需按现有数据生命周期清理。
- 不同父组可以共享相同模板，但有不同的局部 `gap` 覆盖；修改局部 gap 不影响其他父组。

### 6.2 选择/编辑范围

- 蓝框：当前单实例。
- 青绿框：父级列表/组，编辑 gap/padding/方向。
- 紫色：模板编辑；当前样本实线，其它关联实例虚线。
- 右栏显示 `当前选中`、`父容器`、`编辑范围：模板 | 此实例`；修改会影响 N 项时提供实际预览。

### 6.3 文本变化

共享的是**尺寸规则**，不是强制相同最终高度：如最小高度、行数上限、换行/省略、内边距和行高。长标题、表情、国际化、无图标的项都要测试。运行时虚拟列表必须保持稳定项测量策略；若 item 高度变化，应调用已有的测量/缓存失效机制，而不是直接修改 DOM。

### 6.4 编辑时的示例数据

提供空列表、单项、短列表、超长列表、长文本、折叠组、选中/悬停/禁用等模拟状态；不得把虚拟列表未渲染的节点误判为主题缺失。用户数据仅在有必要时用于只读预览，不作为编辑器主题的一部分存储。

## 7. 响应式与跨端适配

### 7.1 默认策略 [确认]

桌面端完整编辑；Android 端使用相同主题的样式资源与设计令牌，但可以拥有独立移动布局覆盖。普通窗口自动伸缩，父容器尺寸不足时重排，最后才采用断点布局覆盖。不能简单以设备名或屏幕分辨率决定所有响应行为。

### 7.2 断点逻辑

- 优先监听**稳定父容器可用宽度**，而非所有子节点自己的瞬时宽度；可以使用 CSS Container Queries，框架不支持则采用受控观察器/测量适配。
- `base` 规则 + 有序 `breakpoints` 覆盖；允许用户在当前预览宽度建立断点，并显示“仅当前断点/基础规则”的作用范围。
- 按属性继承，断点覆盖只覆盖明确指定字段；删除覆盖则继承基础规则。
- 如果变更可能让查询条件翻转，应通过稳定外部容器测量或状态滞回避免重复跳变。
- 横竖屏、DPI、系统文字缩放、触控目标大小应纳入测试；Android 端不得因为继承桌面固定 px 而让控件无法触及。

### 7.3 伸缩/重排的默认优先级

示例：聊天输入栏：输入框 `fill`、发送按钮 `fixed`、组 `gap=8px`。窗口缩小时先压缩输入框到 minWidth；不足时折叠次要按钮、换行或切换为 column/tab 规则，不压扁发送按钮 PNG。分屏在宽屏并排，窄屏优先改为标签切换。[推荐默认]

### 7.4 断点编辑 UX

画布可以直接拖宽/窄；可一键预览宽屏、中屏、窄屏和自定义值。当前断点、继承来源与覆盖字段在属性面板可见。发布前执行连续宽度扫描和关键节点可达性检查，列出冲突/溢出/过小触控区域。

## 8. 背景、图像与超界装饰

### 8.1 背景分层 [确认]

每组件可独立设置：纯色、线性/径向/多站点渐变、PNG、SVG、透明度、位置、旋转/缩放、叠加顺序、圆角、描边、阴影。背景、内容、前景装饰可分开配置；「背景透明度」与「整个组件透明度」不可混为一谈。

### 8.2 背景 fit 必须独立于组件 resize [确认]

支持：`fixed`、`contain`、`cover`、`stretch`、`nineSlice`、`tile`。

**32×64 PNG 放到 32×48 按钮**：

- fixed：素材仍按 32×64 显示，可能溢出；
- contain：24×48，左右各留 4px；
- cover：32×64，视口范围可裁切上下各 8px；
- stretch：32×48，允许形变；
- nineSlice：按四角/边缘/中部的切片规则调整；
- tile：重复平铺（纹理素材）。

按钮本体尺寸与 PNG 绘制尺寸分别处理；默认图标/插画 contain、UI 面板九宫格/拉伸可选。若允许 PNG 在按钮外显示，则“cover 的裁切范围”与“允许溢出到组件外”是**两个独立开关**，不可以把 `overflow: visible` 误当作 `cover` 不裁剪。

### 8.3 九宫格

PNG/SVG 作为可切片边框时可基于 CSS `border-image` 语义或框架等价实现，但需支持中区填充（如适用）、切片值、边厚和中间拉伸/重复。切片坐标与资源原图坐标区分清楚。

### 8.4 背景溢出与跨容器绘制

- `clipped`：受组件/父级裁剪控制；
- `local-visible`：本地允许外绘，若祖先裁剪仍受限制；
- `decoration-portal`：确需越过滚动区/裁剪区的独立装饰，登记语义锚点、实际视口坐标、缩放、可见性与滚动同步，由 Overlay Host 统一绘制。

**不能承诺改 `z-index` 就能越过祖先裁剪。** 所有装饰默认 `pointer-events: none`；交互热区由实际组件（或经明确授权的独立交互对象）决定。装饰跟随组件滚动、隐藏、变形，不得在离屏后留在错误位置。

### 8.5 资源安全

- 导入文件按内容嗅探与格式白名单校验，不依赖后缀；限大小、尺寸和复杂度；哈希去重、异步解码和缓存。
- SVG 必须净化：拒绝脚本、事件处理器、外部网络引用、危险嵌套或内嵌资源；优先安全作为 image 资源展示，不把原始 SVG 直接 innerHTML 注入。
- 主题包需防 Zip Slip/路径穿越和恶意超大解压；不执行导入主题中的任何 JS。
- 素材缺失时替换为基础填色并报错，不阻断应用启动。

## 9. 图层树、堆叠与辅助层 [确认]

### 9.1 图层结构

每个可编辑组件/背景/装饰可出现在图层树，支持嵌套分组、拖动排序、搜索、折叠、批量选择。`parentId` 表示结构归属，不等于任意视觉图层 Z-index。

### 9.2 局部叠放顺序

- 每个布局组内部按层序渲染；实际 CSS 堆叠上下文可能由 opacity/transform/isolation 等创建，适配层统一建模。
- 禁止让用户通过输入极大的全局 `z-index` 强行越过菜单/系统对话框；提供受控的层级带：内容 / 局部悬浮 / 全局菜单 / 模态 / 安全恢复层。
- 菜单、模态、Popover 通过统一浮层服务（支持 top layer/portal 等适合技术栈的能力）防止被裁剪或遮挡。
- 图层重排只影响允许排序的同父/同层对象；跨层移动必须显式改变归属并经过校验。

### 9.3 编辑状态和正式主题状态

- `editor.hidden`：只在编辑器不可见，发布不受影响。
- `runtime.visible=false`：真正保存为运行时隐藏（仅对非受保护项）。
- `editor.locked`：禁止拖动缩放，仍参与响应式计算。
- `editor.solo`：独显当前图层及必要祖先，不影响实际主题。
- 折叠只影响树状列表展开状态。

### 9.4 辅助标注层

与运行时图层分离，拥有网格、标尺、吸附线、间距、锚点、父子虚线、组件边界独立开关。辅助元素不能被导出为正式主题的实际可见节点。

## 10. 主题保存、发布、回退和迁移

### 10.1 状态机

`Published（已发布）`、`Draft（草稿）`、`Editor Session（临时操作状态）`、`Assets Cache（素材缓存）` 明确隔离。

编辑动作只写草稿；自动保存草稿；用户点击发布后执行 schema 校验、资产引用校验、响应式可达性检查、核心入口保护检查，再原子切换到 Published。未通过不得发布但保留草稿。

### 10.2 恢复

- 永久保留内置安全主题。
- 保留上一版发布主题与版本历史。
- 提供与自定义主题无关的安全模式入口/启动参数或等价恢复方法；在主题崩溃/窗口异常时能触发。
- 失败时回到上一版有效主题；不可因自定义主题导致设置无法进入。
- 版本升级时运行 schema migration，迁移失败不覆写原始数据。

### 10.3 导入导出

采用版本化主题包（如 `.sunday-theme`/ZIP + manifest + assets），包括 schemaVersion、资源哈希、预设和布局配置，不含会话正文、密钥、用户绝对路径或任意脚本。导入时先隔离解包与验证，允许预览，不直接覆盖现行主题。[推荐默认]

### 10.4 撤销重做

使用明确的命令/事务日志。一次拖拽为一个撤销步骤，不应每个鼠标 move 都插入历史；资源导入和重挂载也可以撤销。仅对当前草稿生效，历史版本另由 Theme Manager 管理。

## 11. 桌面端、Android 端与插件

### 11.1 桌面端

完整编辑器、拖拽磁吸、图层、素材导入、断点编辑与发布能力。桌面分屏/侧栏行为优先与现有 Sunday 实现融合，不重复制造一套互不相容的分屏服务。

### 11.2 Android 端

使用主题的全局令牌、背景素材和移动端布局覆盖；不实现完整的触控版 PS 工作台。可提供主题选择/重置等必要操作；若终端能力与桌面不同，保留受控 fallback。移动端布局应按触控大小、系统字体比例、安全区域和横竖屏测试。

### 11.3 插件 UI 接口

开放受控的 `registerEditableComponent(...)` 或现有插件注册机制中的等价声明：`semanticId`、`componentType`、`parentSlot`、`editableProperties`、`layoutCapabilities`、`stateVariants`、`previewProvider`、`protectedFields`。不允许插件借主题导入执行自定义 JS。发生插件卸载时，未知节点保留配置但不渲染，安装后可恢复，不得抛出全局异常。

## 15. 风险审查与修正规则

| ID | 级别 | 风险 | 必要修正 | 验收方式 |

### 15.1 最终评审结论

**功能/交互层面**：通过。用户已确认核心机制：尺寸规则独立、智能磁吸、外置三级标注、模板同步、图层树、选择框配色、父子中心虚线、桌面编辑/Android 主题应用。

**架构层面**：有条件通过。需要将约束类型、组件注册权限、特殊浮层与安全回退实施为明确的代码边界，不能只靠文档约定。

## 16. 逐项验收测试（Codex 必须执行）

### 16.1 选择与层级

- T01 单击组件显示蓝框，双击进入子层，Esc 逐级退出；不可调整尺寸的组件没有假手柄。
- T02 选择子组件时，仅显示一条从子中心到直接父中心的虚线，预览时消失。
- T03 模板编辑显示紫色关联实例；退出模板编辑后不留下任何覆盖层。
- T04 图层编辑隐藏、锁定、独显不会改变发布后的主题；实际运行隐藏有单独入口。
- T05 受保护返回/设置/恢复能力不能被主题配置永久隐藏。

### 16.2 磁吸和间距

- T06 边/角/中点/中心线/基线/容器边界吸附可识别目标，禁用吸附不会保存关系。
- T07 将两个按钮吸附为同级 Row，改变其中间距，所有同级间距同步改变。
- T08 0/1/2/8/32px 间距下，标注在外侧完整可读，自动在大括号、`>`、折线之间切换，热点独立可点。
- T09 滚轮 ±1px、Shift±8px、拖动和数值输入结果一致，不劫持画布滚动。
- T10 父子关系重挂载后没有循环，坐标及视觉位置尽量保留，撤销正确。

### 16.3 响应式

- T11 在 320/375/768/1024/1440 逻辑 px 视口或对应容器下检查布局；无不可恢复的组件覆盖。
- T12 连续拖窄和拖宽画布，断点不来回振荡；active breakpoint 说明正确。
- T13 按钮固定尺寸，输入框优先伸缩到下限，随后依配置重排而不强制压扁按钮。
- T14 基础布局修改传递到未覆盖断点；仅当前断点改动不污染宽屏。
- T15 长标题、空列表、多会话、折叠组、系统字号放大仍不丢关键信息/入口。

### 16.4 素材与图层

- T16 同一 32×64 PNG 绑定到 32×48 容器时，fixed/contain/cover/stretch 各结果可见且与文档一致。
- T17 组件背景越界但不吞掉相邻组件的点击；跨滚动装饰随锚点移动，不漂移。
- T18 背景透明度和组件整体透明度可独立调整，状态样式生效。
- T19 无效 SVG、危险脚本、外链资源、过大主题包被拒绝，失败安全回退。
- T20 菜单/模态层始终可见且可操作，焦点正确返回。

### 16.5 数据、跨端与现有 UI

- T21 草稿不影响正式主题；发布成功后重启一致，失败后回退。
- T22 删除会话/增加会话/排序/虚拟滚动后模板样式和父级 gap 保持一致。
- T23 插件注册/卸载不会导致主题崩溃；注册表受保护属性不能被修改。
- T24 Android 应用主题后，安全区域、系统文字放大、横竖屏可用；无需移动端完整编辑器。
- T25 UI-01～UI-06 的修复全部保留现有业务功能。
- T26 损坏最新主题配置模拟启动失败，安全主题可恢复；上一版主题可回滚。
- T27 撤销/重做对单次拖拽、改 gap、改模板、导入素材和重挂载均保持一致。

### 16.6 性能验收

- 编辑器在典型页面和高复杂度测试页面分别采集帧耗时、长任务、内存、资源加载时间。以 60 FPS 作为桌面普通拖拽的优化目标，不承诺任意硬件下绝对达成。
- 动画中避免逐项写布局 CSS 导致大量同步重排；每帧最多一次测量/绘制调度，结束拖拽后提交规则。
- 正常运行代码包不得因为编辑器而无条件加载大型编辑器依赖；素材加载失败不影响基础交互。
- 需要提供测试设备、数据规模和实际测量结果，不能只写“性能良好”。
