## 一、现状复核（改前）

| 项目 | 改前 |
|---|---|
| L1 会话列表 | 不存在独立页面；会话列表在左侧抽屉里（项目分组 + 会话行） |
| 一级导航 | 抽屉页脚的 6 个纯图标（聊天/定时/资料库/插件/设置/远程），无底部常驻 |
| L2 会话详情 | 主区即聊天，但手机无标题栏、无返回列表的层级 |
| 返回键 | 只处理分屏/整版页；抽屉开着会直接退后台 |
| 状态保留 | 整版页用 `v-if` 卸载线程；切页丢滚动与展开状态 |

## 二、本轮已改

1. **底部四入口常驻**（`core/ui/src/components/MobileBottomNav.vue`）
   - 对话 / 工作区 / 任务 / 设置，48dp 触控目标、图标 + 文字、`aria-current` 选中态、底部安全区。
   - 插件与远程连接不再占一级入口；抽屉页脚那排重复入口已下线（`LamToolsApp.vue`）。
2. **L1 会话列表**（`core/ui/src/components/MobileChatList.vue`）
   - 顶部：标题「聊天」、搜索、`+` 新建；搜索本地过滤会话名。
   - 置顶段（读现有 pin 存储）+ 全部会话段；WeChat 式卡片：头像、名称、状态/最近活动、时间、运行中圆点。
   - 点击进入 L2；列表覆盖在主区之上，线程保持挂载。
3. **L1/L2 层级与返回**
   - 手机默认落在 L1；打开会话 → L2；系统返回键在 L2 先回 L1，不会直接退 App。
   - 列表打开时隐藏输入栏；底部导航常驻，切到工作区/任务/设置不走抽屉。
4. **底部让位**
   - `--mobile-bottom-nav-height` 进入输入栏偏移与主区内边距；键盘弹起时输入栏仍在导航条之上。

## 四、阻塞与非前端缺口（搁置）

1. **x86_64 安装包无法重出**：本地 `core/android-runtime/tools/out` 只有 `aarch64`，x86_64 运行时资产缺失；模拟器（x86_64）跑的是 2026-11-09 旧包。要么在 WSL 跑 `build-runtime.sh x86_64` 重出资产（需网络与时间），要么接 arm64 真机验证。
2. **后端缺口**（前端已留位，等接口）：
   - 会话列表的「最后一条消息摘要」「未读数」「待审批数」；
   - 按消息正文搜索（当前只能按标题本地过滤）；
   - 置顶/静音/归档的服务端持久化（置顶目前是本地 localStorage）；
   - 会话关联任务/文件聚合接口。
