# 产品侧栏标题设计

## 目标

将工作台左侧栏顶部的通用标题改为当前产品名称：Core 工作台显示 `Core`，Writer 工作台显示 `Writer`。视觉语义从泛化的“Projects”转为当前所在产品，同时保留下方项目与会话层级。

## 范围

- 共享工作台外壳接收可配置的侧栏标题。
- Core 与 Writer 分别传入自身的简短产品名。
- 保留标题右侧的新建按钮、项目列表、会话列表及其全部行为。
- 沿用现有主题、字号体系和交互状态，不引入新的数据模型或导航层级。

## 交互与可访问性

- 标题仅承担当前产品标识，不可点击。
- 新建按钮的键盘操作、焦点样式和无障碍标签保持不变。
- 窄侧栏下标题与操作按钮不得重叠或溢出。

## 验收

1. Writer 工作台左上角显示 `Writer`。
2. Core 工作台左上角显示 `Core`。
3. 项目创建、项目选择、会话选择和侧栏折叠行为无回归。
4. 共享 UI 的组件测试、类型检查和 Writer 前端构建通过。

## 非目标

- 不把 Core 或 Writer 改造成项目分组。
- 不调整现有项目与会话数据。
- 不照搬参考图的搜索、置顶、最近使用或归档功能。
