# 产品项目侧栏设计

## 目标

将工作台左侧栏整理为参考图的信息层级：顶部显示当前产品名称，项目按“置顶 / 最近 / 更早”分区，项目内继续展示会话。

## 范围

- 共享工作台外壳接收可配置的侧栏标题。
- Core 与 Writer 分别传入自身的简短产品名。
- 项目可在侧栏直接置顶或取消置顶，偏好按产品保存在本机。
- 项目右侧统一使用 `…` 菜单收拢新建会话、置顶、展开/收起、项目设置和删除；删除作为独立危险项。
- 会话默认显示运行状态点；鼠标悬停或键盘聚焦时，状态点切换为置顶与删除图标按钮。
- 置顶会话在所属项目内排到未置顶会话之前，原始会话序号保持不变。
- 未置顶项目按最近活动时间自动分区：30 天内归入 `RECENT`，其余归入 `EARLIER`。
- 项目最近活动时间取其会话最新的 `updatedAt`，缺失时回退到 `createdAt`；没有有效时间的项目归入 `EARLIER`。
- 各分区内按最近活动时间降序排列。
- 保留标题右侧的新建按钮、项目列表、会话列表及其全部行为。
- 沿用现有主题、字号体系和交互状态，不引入新的数据模型或导航层级。

## 交互与可访问性

- 标题仅承担当前产品标识，不可点击。
- 置顶按钮提供明确的文本提示、无障碍标签和键盘焦点状态。
- 项目菜单支持点击外部或 Escape 关闭。
- 新建按钮的键盘操作、焦点样式和无障碍标签保持不变。
- 窄侧栏下标题与操作按钮不得重叠或溢出。

## 验收

1. Writer 工作台左上角显示 `Writer`，Core 工作台显示 `Core`。
2. 置顶项目出现在 `PINNED`，刷新后仍保持；取消后回到时间分区。
3. 项目菜单包含当前项目可用操作，且不可越出侧栏或被裁切。
4. 会话 hover/focus 时显示置顶与删除，离开后恢复状态点。
5. 30 天内活跃项目显示在 `RECENT`，更早或无时间项目显示在 `EARLIER`。
6. 项目创建、项目选择、会话选择和侧栏折叠行为无回归。
7. 共享 UI 的组件测试、类型检查和 Writer 前端构建通过。

## 非目标

- 不把 Core 或 Writer 改造成项目分组。
- 不调整现有项目与会话数据。
- 不增加搜索和归档功能。
