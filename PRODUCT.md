# Product

## Register

product

## Users

LamTools is used by operators and developers who run local AI-assisted writing, coding, and creative workflows from a desktop or browser workspace. They are usually in a task flow: starting or resuming a session, monitoring progress, editing settings, and reviewing generated output.

## Product Purpose

LamTools provides a unified Core — a reliable, product-neutral workbench shell for sessions, runtime state, configuration, and task execution. Success means Core is a dependable, independently usable Agent that can host long-running AI tasks without product-specific coupling.

## Brand Personality

Calm, direct, capable. The interface should feel like a dependable work tool: clear hierarchy, low visual noise, predictable controls, and enough polish that users trust long-running AI tasks without needing decorative reassurance.

## Anti-references

Avoid marketing-style landing pages, oversized hero treatments, decorative gradients, glass panels, inconsistent custom controls, and UI that hides operational state behind visual flourish. Avoid product-specific styling leaking into shared core surfaces.

## Design Principles

- Put task state first: users should quickly see what is running, waiting, failed, or done.
- Keep shared UI product-neutral: core surfaces must not encode product-specific assumptions.
- Prefer dense, readable tools over decorative composition.
- Treat empty, loading, error, and disconnected states as first-class workflow states.

## Accessibility & Inclusion

Target WCAG AA for core product surfaces. Keyboard access, visible focus states, readable contrast, reduced-motion safety, and non-color-only state indicators should be expected across the Core UI.
