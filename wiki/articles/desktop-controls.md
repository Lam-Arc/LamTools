# 桌面窗口与导航

**桌面导航**（Desktop navigation）是 Sunday 通过应用侧栏、窗口标题栏和全屏工作区完成页面切换与窗口控制的方式。

| 信息框 | |
|---|---|
| 类型 | 导航与窗口控制 |
| 入口 | 左侧应用导航 |
| 主要区域 | 聊天、定时任务、资料库、插件、设置 |
| 搜索快捷键 | Ctrl+K |
| 侧栏 | 左右侧栏均可固定或收起 |
| 适用平台 | 桌面端 |

## 概述

桌面版的导航分成两层：最左侧的窄导航列负责切换整个工作区，页面内部的侧栏负责切换项目、会话或设置分区。理解这两层的分工，可以避免把“页面没打开”误判成“数据丢了”。<sup>[1]</sup>

## 应用导航

左侧窄导航列提供以下入口：

| 入口 | 打开的内容 | 呈现方式 |
|---|---|---|
| 聊天 | 项目与会话 | 保留项目侧栏和会话侧栏 |
| 定时任务 | 任务列表与历史 | 全屏区域 |
| 资料库 | 资料与视图 | 全屏区域 |
| 插件 | 插件管理 | 会话侧栏改为分区导航 |
| 设置 | 应用设置 | 会话侧栏改为分区导航 |
| 账号 | 账号信息 | 独立面板 |

点击入口会切换主工作区，而不是新建窗口。窗口空间较窄时布局会调整，但主要入口仍在左侧导航中。<sup>[1]</sup>

## 标题栏与侧栏

窗口标题栏显示当前模式，并提供侧栏固定状态的控制。左右侧栏都可以固定或收起，以腾出内容空间。

- 应用存在多个模式时，可以从侧栏顶部的模式入口切换；只有一个模式时会显示不可切换提示。
- 搜索可以从侧栏的“搜索”按钮打开，也可以按 Ctrl+K。
- 侧栏被隐藏时，先用标题栏的固定控制恢复，或切回聊天导航；不要通过重置项目数据来找回侧栏。

## 全屏区域

资料库、搜索和定时任务以全屏区域打开，按返回或 Esc 离开。设置与插件页会把原本的会话侧栏改成分区导航，因此在这两个页面里看不到项目和会话列表，这是正常行为。

从全屏区域回到聊天后，原来的项目与会话选择仍然保留。

## 桌面能力边界

桌面版可以使用本机目录选择、文件拖放，以及用系统默认应用打开文件。项目路径对应本机工作目录。

手机配对、相机来源等其他平台功能不属于桌面导航的范围。窗口重新启动后如果出现后台停止提示，按界面提示重启应用以恢复服务；正常切换页面不需要重启。

## 电源与内存续跑

桌面设置“通用”分区提供三项与长时间运行有关的选项：<sup>[2]</sup>

- **保持电脑运行**：任务进行时阻止电脑因空闲而休眠。
- **内存中断自动续跑**：系统因内存不足中断后，等待可用内存恢复再继续。
- **自动继续的内存阈值（GB）**：可用内存达到该值后才继续，默认 4 GB，调高更保守但等待更久。

这些选项只处理已识别的内存中断，网络、密钥、权限或代码错误仍需针对原因处理。

## 提示

- 找不到某个页面时，先看左侧导航是否已经切换工作区，再看页面内是否还有一层侧栏。
- Ctrl+K 是统一的搜索入口，比逐层点开资料库更快。
- 侧栏布局是界面状态，不会改变项目或会话数据。

## 已知问题

- 窄窗口会调整布局，部分入口可能收进图标或折叠区域。
- 手机端导航不在本条目范围内。
