# 安装、启动与版本

**安装**（Installation）指把 Sunday 桌面版装到本机并完成第一次启动。安装包已经把运行所需的主要程序打包在一起，普通用户不需要先搭建开发环境。

| 信息框 | |
|---|---|
| 类型 | 安装与启动 |
| 支持平台 | Windows x64、Linux x64；macOS 尚未支持 |
| 常见形式 | Windows 安装程序；Linux AppImage 与 Debian 包 |
| 配置位置 | 安装后由应用管理，不需要手工编辑 |
| 版本查看 | 设置 → 关于与更新 |
| 数据保留 | 升级安装默认保留用户数据 |

## 概述

Sunday 由桌面程序和一个本机后台程序组成。桌面程序负责窗口与界面，后台程序负责模型请求、工具执行与会话存储。安装包会同时安装两者，因此“窗口能打开”和“功能可用”是两个不同的检查点。<sup>[1][2]</sup>

## 选择安装包

从项目的正式发布渠道下载与电脑系统和处理器相符的版本：

- Windows 使用安装程序，文件通常以 `.exe` 结尾。
- Linux 提供 AppImage 与 Debian 包，按发行版习惯选择。
- macOS 目前没有受支持的桌面分发。

不要把源代码压缩包当成安装包，也不要把不同系统的文件混用。具体提供哪些文件，以该版本发布页为准。

下载入口：[Sunday 正式发布页](https://github.com/Lam-Arc/LamTools/releases)。本 Wiki 只描述桌面端，不包含手机安装、配对或操作流程。

## 第一次启动

按安装程序提示完成安装并启动。第一次启动会进入配置引导，其中最重要的是模型服务：

1. 选择服务模板或自定义服务。
2. 填写密钥、服务地址与模型名称。
3. 保存后发送一句简单的话，确认能收到回答。

软件能打开，只说明桌面程序启动了；模型仍需单独配置并具备可用额度。首次使用建议跟随[快速开始](quick-start.md)，先完成一轮问答，再处理文件。<sup>[3]</sup>

如果之前装过 Sunday，升级后先核对项目、会话和模型配置是否仍能读取。重要资料应先备份。

## 确认版本

在“设置 → 关于与更新”中可以看到当前版本，并使用应用提供的更新检查。不同版本的按钮、默认设置和内置插件可能有变化；词条按仓库当前实现编写，不保证与所有旧安装包完全一致。

看到界面与词条不同时，先记下版本号，再按功能名称寻找对应设置，不要按位置记忆去点击。

## 启动异常时

| 现象 | 可能原因 | 先做什么 |
|---|---|---|
| 窗口出现但一直无法连接 | 本机后台程序未就绪 | 完全退出后重新启动 |
| 提示后台停止 | 后台进程退出 | 按界面提示重启应用 |
| 能打开但问答失败 | 模型未配置或额度不足 | 检查模型与网络 |
| 升级后项目消失 | 数据目录或配置未加载 | 先备份，再检查数据目录 |

不要为了修复启动问题直接删除数据目录。完整退出再启动、保留错误提示，通常比反复重装更有用。详细处理见[故障排查](troubleshooting.md)和[查找本地数据和制作备份](data-backup.md)。<sup>[2]</sup>

## 提示

- 升级前先备份重要项目与会话，不要用“以前没出过问题”代替备份。
- 安装包和用户数据是两回事；卸载或覆盖安装前先确认数据目录位置。
- 公司网络或代理可能阻止更新检查，但不影响已安装版本的本机使用。

## 已知问题
