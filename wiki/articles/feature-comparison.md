# 容易混淆的功能怎么选

**功能选择**（Feature comparison）用“你现在想做什么”来区分相似功能。选择前先问自己：是在找东西、保存信息，还是启动工作？

| 信息框 | |
|---|---|
| 类型 | 选择指南 |
| 覆盖场景 | 找资料、保存信息、安排工作、扩展能力 |
| 判断方式 | 先看目的，再看范围 |
| 是否替代词条 | 否，只给选择入口 |

## 找资料时

| 目的 | 使用什么 | 需要知道 |
|---|---|---|
| 找以前的聊天、方案或相关记录 | [全局搜索](search.md) | 查应用已接入的内容 |
| 找项目目录中的文件和句子 | [文件搜索](file-search.md) | 查本机真实文件 |
| 找公开网页资料 | [网页搜索](web-search.md) | 需要网络与可用搜索服务 |
| 读取已经知道的网址 | [网页抓取](web-fetch.md) | 不等于浏览器点击操作 |
| 从已接入知识库取片段 | [RAG](rag.md) | 必须先有提供方和索引 |

不要因为一项搜索没有结果，就判断其他地方也没有相关内容。它们的查询范围不同。

## 保存信息时

| 目的 | 使用什么 | 需要知道 |
|---|---|---|
| 留住整个讨论过程 | [会话](sessions.md)与[导出](session-export.md) | 模型不一定每次都参考全部历史 |
| 保存长期偏好和事实 | [记忆](memory.md) | 是笔记，需要维护准确性 |
| 让项目规则持续生效 | [上下文文件](context-files.md) | 用来约定怎么工作 |
| 复用一套执行方案 | [方案](plans.md) | 方案文档不会自行执行 |
| 找生成的文件 | [成果库](artifacts.md) | 文件登记与文件本身分开 |

## 安排工作时

| 目的 | 使用什么 | 需要知道 |
|---|---|---|
| 当前讨论完再做下一件事 | [排队消息](queued-messages.md) | 未发送的要求当前轮次可能不知道 |
| 让主助手分派独立任务 | [子代理](sub-agents.md) | 仍要核对各子任务结果 |
| 跟踪本次工作的步骤 | [清单](checklists.md) | 标记完成不等于文件已验证 |
| 让任务围绕持续目标推进 | [目标](goals.md) | 和固定时刻触发不同 |
| 到指定时间启动 | [定时任务](arrange.md) | 需要运行环境和权限 |
| 把多个步骤固定连接起来 | [工作流](workflow.md) | 要配置输入、节点和恢复条件 |

## 扩展能力时

| 能力 | 提供什么 |
|---|---|
| 技能 | 做事方法 |
| 工具 | 具体动作 |
| 插件 | 打包多种扩展 |
| MCP | 接入外部工具服务 |

遇到缺功能时，先确定缺的是哪一层，避免安装一份技能后期待它自动获得原本不存在的浏览器或账号权限。

## 提示

- 先在“找、存、做”三个动词里选一个。
- 涉及文件时，以磁盘上的真实文件为准。
- 涉及权限时，区分“工具是否存在”和“是否允许执行”。
