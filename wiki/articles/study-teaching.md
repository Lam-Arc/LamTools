# Study 如何讲解知识

**Study 讲解**（Teaching）是学习工作区根据学科、基础和当前卡点选择表达方式的能力。它不会要求每个问题都经过同一套流程。

| 信息框 | |
|---|---|
| 类型 | 讲解规则 |
| 依据 | 学习目标、现有基础、当前困难 |
| 定量学科 | 先定义公式，再补白话解释与推导 |
| 解释性学科 | 先讲情境，再归纳原则 |
| 是否自动考试 | 否 |
| 是否扩展权限 | 否 |

## 概述

讲解方式服务于理解，而不是展示知识量。用户说明基础、目标、卡点和希望的深度后，Study 会尽量用完整例子、概念联系和必要来源来解释。<sup>[1][2]</sup>

这些是讲解要求，不是权限扩展。Study 仍然受模型、工具和审批约束。

## 按学科选择表达方式

| 学科类型 | 讲解顺序 |
|---|---|
| 数学、物理、化学、生物、统计、计算机、工程 | 定义或公式 → 可感受的白话解释 → 推导 |
| 历史、哲学、文学、法律、政治、伦理、艺术 | 具体情境 → 原则 → 情境与原则的对应 |

解释性学科还要说明：

- 类比在哪些条件下成立。
- 类比在哪些条件下不成立。

定量学科的白话解释应当能被检查，而不只是听起来顺耳。

## 从一个难点开始

| 学习状态 | 请求方式 |
|---|---|
| 刚入门 | 要一个带步骤和理由的完整例子 |
| 会算但说不清 | 要求把例子、图示和原则连起来 |
| 不会选方法 | 比较相近方法的适用条件 |
| 觉得太快 | 要求补上缺失步骤 |
| 还是不懂 | 换一种表示，或缩小难点 |

不要用“再讲一遍”解决理解问题。换表示、补中间步骤、缩小范围通常更有效。

可以明确要求：

> 请先给提示，不要直接给最终答案。

## 来源、图示与边界

- 稳定基础知识不必每次联网。
- 遇到标准、版本、近期事实或用户指定材料时，先查原始来源。
- 标明不确定处，不要把推测写成事实。
- 图示要解释如何阅读，并与单位、方向和公式一致。
- 生成图片或网页内容不能证明事实。
- 真实元件、法律文本和测量数据要依靠可靠来源。

讲完一节不会自动考试，也不会自动标记掌握。是否继续练习由学习目标决定。

## 提示

- 先说明“我已经会什么、卡在哪里”。
- 要求例子带理由，而不是只给答案。
- 对专业术语，要求结合当前学科解释并核对原文。

## 已知问题

- 讲解质量受模型能力影响。
- 图示不保证与真实测量或法律文本完全一致。
