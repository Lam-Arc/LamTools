# 设置总览

**设置**（Settings）是 Sunday 桌面端集中管理模型、界面、工具、权限、上下文和更新的入口。设置按分区组织，每个分区在同一页面内打开。

| 信息框 | |
|---|---|
| 类型 | 应用设置 |
| 入口 | 应用侧栏的“设置” |
| 分区数 | 9 个应用分区，另有插件与项目分区 |
| 保存方式 | 部分即时保存，部分需要“保存” |
| 作用范围 | 应用级与项目级分开 |

## 概述

设置页面由左侧分区导航和右侧内容组成。打开设置后，原来的会话侧栏会改作分区导航，因此看不到项目和会话列表；返回聊天即可恢复。

不同分区的保存方式并不一致：有的选择后立即生效，有的需要点击“保存”，还有的要等应用重启。<sup>[1]</sup>

## 设置分区

| 分区 | 主要内容 |
|---|---|
| 模型与供应商 | 模型服务、密钥、模型清单 |
| 通用 | 语言、电脑保持运行、内存中断续跑 |
| 界面 | 主题、密度、区域配色 |
| 工具模式 | 工作模式与工具启用范围 |
| 权限 | 审批策略与默认权限 |
| 手机控制 | 非桌面端功能 |
| 上下文 | 上下文文件、全局规则 |
| Sub agent | 子代理配置 |
| 关于与更新 | 版本、更新检查 |

插件页与项目设置使用同一套分区机制，但只显示各自的分区。<sup>[2]</sup>

## 查找与保存

模型页、供应商页、模型组和工具模式各自提供搜索框，只过滤当前分区的内容。

保存方式可以分成三类：

- **需要保存**：上下文文件与全局规则有明确的“保存”按钮，离开前要确认没有留下草稿。
- **即时保存**：多数外观与开关类选项在选择后立即写入。
- **需要重启**：已连接的服务或后台进程相关设置，页面会注明。

遇到加载失败或错误提示时，优先使用分区内的刷新或重试，不要重复创建相同条目。

## 配置范围

设置分为两个作用范围：

| 范围 | 包含内容 |
|---|---|
| 应用级 | 全局规则、网络选项、默认权限、外观、模型服务 |
| 项目级 | 项目规则、部分子代理配置、项目工作目录相关选项 |

单次运行时的模型、思考档位和权限可以不同于默认设置。修改全局默认值，不会改写已经开始的单次运行选择。

## 项目设置

项目设置位于具体项目内部，只影响该项目。全局设置与项目设置同时存在时，项目级选项优先用于该项目。<sup>[3]</sup>

## 提示

- 改完设置后先确认是否需要点击“保存”，再离开页面。
- 修改模型或权限后，用一轮简单问答验证，不要直接处理重要文件。
- 不确定某项是全局还是项目级时，先看页面标题和分区位置。

## 已知问题

- 个别分区名称保留英文，例如“Sub agent”，用于对应配置概念。
- 不同版本的分区数量与名称可能不同。
