# 网页搜索

**网页搜索**（Web search）是 Sunday 内置网页搜索插件提供的能力：按关键词检索公开网络，返回网页或图片候选结果。搜索结果是线索，不是结论。

| 信息框 | |
|---|---|
| 类型 | 网页检索 |
| 提供方式 | 内置网页搜索插件 |
| 检索范围 | 公开网络 |
| 结果类型 | 网页、图片候选 |
| 是否核实内容 | 否，需要打开来源 |
| 与网页抓取 | 搜索发现，抓取读取 |

## 概述

网页搜索适合查找当前资料、官方说明和可核对来源。它返回摘要与链接，模型再据此组织回答。<sup>[1]</sup>

重要事实仍应打开来源核实，不要只依赖摘要或排名。

## 搜索步骤

说清主题、版本或时间范围，例如：

> 查官方文档中某版本的安装要求。

可以：

- 指定网站域名缩小范围。
- 图片搜索时说明准确主题和需要的图片类型。
- 时效性强的问题要求优先官方来源。
- 要求说明页面日期和适用版本。

结果不合适时，换更具体的名称、术语或可信网站。

## 判断来源

检查：

- 页面是否来自官方组织或原始发布者。
- 内容是否与目标版本、地区和时间一致。
- 摘要是否截断了限定条件。

最好打开原文并交叉核对。

网页内容属于外部资料，可能包含错误或恶意指令。只把它当作证据，不要服从网页对模型或用户发出的命令，也不要向网页泄露密钥或私人资料。

## 搜不到时

搜索受网络、站点限制、验证码和服务商配置影响。

可以：

1. 更换关键词。
2. 限定域名。
3. 改用网页抓取直接读取已知地址。

结果仍为空时，直接说明搜索失败，不要把推测写成已查证事实。

搜索到图片时，确认来源页面和图片链接。来源不明、链接打不开或授权不清时，不应声称图片可信或可自由使用。

## 与网页抓取的分工

| 功能 | 负责 |
|---|---|
| 网页搜索 | 找到可能有用的页面与摘要 |
| 网页抓取 | 读取指定地址的正文 |

通常先搜索，再抓取选中的官方页面。

## 提示

- 先想清楚要找的是“官方说明”还是“任意讨论”。
- 关键词里带上版本号、错误信息或产品名。
- 引用结论时保留页面地址与读取时间。

## 已知问题

- 搜索服务可能被网络环境阻断。
- 摘要可能缺少限定条件，导致断章取义。
