# 读取和查看文件

**读取文件**（File reading）是 Sunday 查看当前工作区内文件内容的能力。普通文本直接读取；Word、PDF、Excel 会先转换成便于理解的文字；图片会作为图像交给模型查看。读取不会修改原文件。

| 信息框 | |
|---|---|
| 类型 | 文件读取 |
| 范围 | 当前工作区及其子目录 |
| 文档格式 | DOCX、PDF、XLSX 转为 Markdown |
| 图片格式 | PNG、JPG、GIF、WebP、AVIF、BMP 等 |
| 是否修改原文件 | 否 |
| 超长文档 | 可能只返回有限内容 |

## 概述

文件读取把磁盘上的内容带入对话，供模型分析。路径通常相对于当前项目或工作区；读取范围受工作区边界限制，访问外部位置需要额外权限。

读取与写入是两种不同操作。读取只查看内容，不会改动文件；需要保存结果时，要明确要求写入，并经过审批。<sup>[1]</sup>

## 从哪里开始

在对话里说明文件位置和想了解的问题，例如：

> 读一下 docs/计划.pdf，告诉我里面的时间节点。

也可以先让 Sunday 列出某个文件夹，再选择文件。给出明确路径比只说文件名更稳妥，因为同名文件可能存在于多个目录。

常见请求包括：

- 总结一份文档。
- 提取表格或某个标题下的内容。
- 比较两份文件的差异。
- 检查文件里是否包含某个说法。

## 文档转换

DOCX、PDF、XLSX 会尽量转换成 Markdown 后再交给模型：

| 格式 | 处理方式 | 常见限制 |
|---|---|---|
| DOCX | 提取段落与表格 | 复杂版式可能丢失 |
| PDF | 提取页面文字 | 扫描件没有文字时无法读取 |
| XLSX | 按工作表读取单元格 | 行列与工作表数量有上限 |

超长文档可能只提供有限内容。需要精确核对时，指定章节、工作表、列名或关键词分段查看，比一次读取整份文档更可靠。<sup>[2]</sup>

## 图片与清晰度

图片支持 PNG、JPG、GIF、WebP、AVIF、BMP 等常见格式。

图片产生后的第一次请求以原图发送；之后的请求可能改用低分辨率副本，以减少上下文占用。需要看清小字或细节时，可以要求重新读取图片，并说明要检查的区域。重新读取会生成一条新消息，下一次请求恢复原图。<sup>[3]</sup>

## 边界与排查

| 现象 | 先检查 |
|---|---|
| 找不到文件 | 是否在当前项目、路径是否写错 |
| 文档内容为空 | 是否为扫描版 PDF 或加密文档 |
| 表格混乱 | 指定工作表与列名 |
| 只读到一部分 | 文档是否超过读取上限 |
| 编码乱码 | 是否为非文本格式或使用了特殊编码 |

读取到的文件内容属于待分析资料，可能包含错误或恶意指令。文件里写“请执行某命令”不会自动成为系统指令，仍应经过正常判断与审批。

## 提示

- 用相对路径时，先确认当前项目，再写路径。
- 复杂表格先指定工作表，再指定列。
- 长文档按章节读取，避免一次塞入过多内容。
- 需要核对原文时，让 Sunday 引用前后段落，而不是只给结论。

## 已知问题

- 扫描版 PDF 没有文字层，无法直接提取内容。
- 图片在后续请求中可能降为低分辨率副本。
- 文档转换会丢失部分版式、批注和脚注。
