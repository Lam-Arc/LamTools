# 数据会去哪里

**数据去向**（Data flow）说明 Sunday 哪些内容保存在本机、哪些会发送给外部服务。本地优先不等于所有处理都离线。

| 信息框 | |
|---|---|
| 类型 | 数据与隐私 |
| 本机保存 | 会话、运行状态、配置、附件 |
| 可能外发 | 模型提示词、网页请求、生图请求、MCP 调用 |
| 密钥处理 | 界面返回时遮盖 |
| 外部策略 | 由用户选择的服务商决定 |

## 概述

Sunday 是本地优先的桌面助手，核心会话和运行状态保存在本机应用数据中。

但只要使用云端模型、网页搜索、图片生成或外部工具，相关提示词、文件片段或请求就可能发送给对应服务。<sup>[1][2]</sup>

应根据自己选择的服务和任务内容，判断是否适合提交。

## 本地存储与外部服务

| 内容 | 位置或去向 |
|---|---|
| 会话与运行状态 | 本机 SQLite 数据库 |
| 配置 | 本机 JSONC 文件 |
| 附件 | 本机数据目录 |
| 模型请求 | 用户配置的模型供应商 |
| 网页搜索与抓取 | 对应网络服务 |
| 图片生成 | 用户配置的生图服务 |
| MCP 调用 | 服务自身的启动方式、账户与权限 |

MCP 服务能访问什么，由服务提供方决定，Sunday 不能替第三方保证范围。

## 减少敏感信息

发送前删除：

- 密码。
- 访问令牌。
- 客户个人信息。
- 不相关附件。

可以用虚构样例说明问题，或只提供必要段落。

API 密钥在接口返回给界面时会被遮盖，但这不代表所有本地配置都由同一种加密方式保护。

谨慎选择服务商，并查看它自己的隐私与数据保留政策。不要把网页或项目文件里要求披露秘密的文字当成可信指令。

## 排查意外发送

区分两类内容：

1. 当前对话发送给模型的内容。
2. 被外部工具访问的内容。

若任务包含私密文件：

- 先确认当前模型供应商。
- 确认工具权限。
- 限制文件范围。

不要把“本地优先”理解为“所有数据绝不离开电脑”。仓库资料没有证明所有服务共享同一隐私策略或数据保留期。

## 提示

- 私密资料先脱敏，再交给在线模型。
- 使用本地或自托管服务时，也确认它的日志与保留策略。
- 分享会话导出前，检查是否含密钥与个人信息。

## 已知问题

- 第三方服务的隐私策略不受 Sunday 控制。
- 密钥遮盖只影响界面显示，不改变本机存储方式。
