# 分屏

**分屏**（Split Pane）是 Sunday 桌面版在同一主窗口中同时显示聊天、其他页面、网页和文件的工作区功能。主区保留原有标题栏，辅助分屏使用标签管理各自的内容，不需要新开应用窗口。<sup>[1][2]</sup>

| 信息框 | |
|---|---|
| 类型 | 桌面工作区布局 |
| 布局 | 左右、上下组合，可调整比例 |
| 内容 | 页面、网页、文本文件、文件预览、文件树、子代理过程、辅助对话 |
| 状态 | 标签与布局保存在本机 |
| 文本编辑限制 | 4 MB 以内的文本文件 |
| 适用版本 | 0.3.22-a3 内部测试版 |

## 概述

分屏用于同时对照多份内容，例如在聊天旁查看网页，或在文件树旁编辑文本。分屏属于同一个工作区；各块内容保留自己的标签和导航状态，主区不增加一排标签。<sup>[1][2]</sup>

## 布局与标签

### 拆分与移动

分屏入口提供左右、上下拆分及布局操作。辅助屏中的“打开内容”入口可新增标签。标签可在屏之间移动，拖到目标屏中央可合并为标签，拖到边缘可创建相邻分屏。分隔条用于调整两块区域的比例。<sup>[1][3]</sup>

### 聚焦、收起与恢复

聚焦只显示当前屏，收起分屏会隐藏辅助布局。恢复后继续使用原布局。桌面窗口过小时，工作区会临时聚焦一块屏，而不是删除其他屏；空间恢复后可以继续使用原组合。布局与标签保存在本机。<sup>[1][3][4]</sup>

关闭子代理过程的标签只关闭视图，不表示终止该代理。需要停止运行时仍使用对应的运行控制。<sup>[2][5]</sup>

## 支持的内容

| 内容 | 用途 | 边界 |
|---|---|---|
| 应用页面 | 并排打开资料库、设置、插件或定时任务 | 页面内部保留自身导航 |
| 浏览器 | 查看网页、前进、后退或刷新 | 仅支持 HTTP、HTTPS；需要桌面运行环境 |
| 文本编辑器 | 打开、修改和保存文本 | 绑定项目，限制为 4 MB 以内的文本文件 |
| 文件预览 | 查看图片、音视频、PDF 与 Office 文件 | 实验性功能；只读，PPTX 不还原完整版式 |
| 文件树 | 浏览当前目录并打开文件 | 文件由绑定的项目目录确定 |
| 子代理过程 | 查看运行、输出和等待状态 | 来自其他聊天的过程需回来源聊天处理提问和审批 |
| 辅助对话 | 对照来源聊天进行分析 | 主聊天助手为只读分析用途 |

不同内容使用独立标签。切换主区页面不会自动把其他分屏的内容替换成当前页面。<sup>[2][5][6]</sup>

## 保存与冲突

### 共享文件与草稿

同一工作区中打开同一文件时，共用编辑状态。尚未保存的文本会备份为本机草稿；关闭编辑器或页面时，涉及未保存内容的操作会经过页面的保存保护。草稿备份不等于文件已经保存。<sup>[7]</sup>

### 外部修改

保存前会检查文件是否已被其他程序修改。发生修改、删除或保存期间冲突时，不会静默覆盖；编辑器保留当前草稿并说明问题。另存为后，原文件与新文件分别管理。<sup>[7][8]</sup>

## 主聊天助手

辅助对话可绑定来源聊天。每次提问会读取该来源聊天的真实上下文，来源不存在时明确报错，不会悄悄改成当前主区聊天。界面提供返回来源聊天的入口，并标明只读助手。<sup>[6][9]</sup>

只读助手用于理解和分析来源内容，不能借助命令、配置或多动作工具扩大为写入能力。辅助对话也可作为独立对话打开，界面会区分两种来源。<sup>[6][9]</sup>

## 提示

- 对照内容适合放在辅助屏，主区可以继续保留原聊天。
- 保存失败时应先查看冲突说明，确认草稿与磁盘文件的差异。
- 收起分屏与关闭内容不同；需要临时腾出空间时，可以使用收起或聚焦。

## 已知问题

1. 分屏浏览器依赖桌面原生网页视图，不能把任意协议或任意文件当作网页打开。
2. 文本编辑器不是办公文档排版软件，文件大小和编码需要满足文本读取条件。
3. 文件预览为实验性功能，PPTX 只显示文字、备注和内嵌图片，Excel 每个工作表最多显示前 500 行与前 60 列。
3. 其他来源聊天的审批和提问不会因打开过程标签而转移归属。
4. 内部测试版的分屏入口与交互细节仍可能随测试调整。
