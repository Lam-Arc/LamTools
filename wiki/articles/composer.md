# 聊天输入框

**聊天输入框**（Composer）是 Sunday 提交任务、补充说明、调用技能命令和查看运行设置的主要入口。它位于聊天页面底部。

| 信息框 | |
|---|---|
| 类型 | 输入入口 |
| 位置 | 聊天页面底部 |
| 主要功能 | 发送消息、停止运行、技能命令、附件、运行选项 |
| 草稿 | 按会话保存 |
| 发送键 | Enter 发送，Shift+Enter 换行 |

## 概述

输入框同时承担三件事：写消息、选择运行方式、发起或停止任务。任务运行时，发送按钮会变成停止操作；停止后仍可以继续补充指令。<sup>[1]</sup>

## 编写与发送

- 描述目标、背景、期望结果和相关文件。
- 多行文本会作为同一条消息发送。
- 空白输入不能发送。
- Enter 发送，Shift+Enter 换行。

任务运行中按 Enter，消息会进入待发送队列；按 Ctrl+Enter 则会尝试作为引导送入当前回合。两者的区别见[消息引导与排队](queued-messages.md)。

## 技能与快捷操作

输入斜杠后，可以从命令建议中选择可用技能或动作。

- 已识别的技能命令会作为独立的技能输入项提交。
- 命令前后的普通文本仍会保留，并作为上下文传入。
- 拼写未匹配的命令不会被当成技能执行。
- 命令列表来自当前可用的技能与插件能力；启用或禁用后会变化。

## 运行控制与限制

输入框上方或附近会显示模型、思考模式和权限预设等运行选项。具体可选项取决于当前模型和应用配置。

以下情况会限制发送：

| 情况 | 表现 |
|---|---|
| 输入为空 | 发送按钮不可用 |
| 历史仍在加载 | 暂时不能发送 |
| 当前页面不允许聊天 | 输入框隐藏或禁用 |
| 有待确认事项 | 可能要求先处理审批或提问 |
| 全屏资料库或设置 | 输入框隐藏，回到聊天后恢复 |

## 附件与草稿

附件通过“添加附件”或拖入文件补充，正文与附件一起提交。附件在发送前可以预览、重试或移除，详见[附件](attachments.md)。

切换会话时，未发送的文字会按会话保存，离开当前对话不必手动复制。

## 提示

- 把“做什么、不要做什么、怎么算完成”写在同一段里。
- 需要影响当前运行中的任务时，用 Ctrl+Enter 而不是普通发送。
- 斜杠命令前后的文字都会被保留，可以在命令后继续补充要求。

## 已知问题

- 全屏页面会隐藏输入框，这是界面行为，不是故障。
- 技能命令列表随安装内容变化，旧文档中的命令不一定仍然存在。
