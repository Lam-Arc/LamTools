# 会话导出

**会话导出**（Session export）是 Sunday 把一条会话保存成本机文件的动作。导出生成副本，不删除原会话，也不把内容自动导入其他项目。

| 信息框 | |
|---|---|
| 类型 | 会话导出 |
| 入口 | 左侧会话条目的菜单 →“导出” |
| 格式 | Markdown、TXT、JSONL、Agent Handoff、完整归档 |
| 保存位置 | 由系统文件保存窗口选择 |
| 对原会话的影响 | 无，原会话保留 |

## 概述

导出用于留存、交接或离线查阅。不同格式适合不同用途：可读文本适合阅读，结构化格式适合程序处理，完整归档适合保留附件与结构。<sup>[1]</sup>

导出前检查会话标题与项目归属，避免把相似名称的对话存错。

## 导出格式

| 格式 | 适合用途 | 特点 |
|---|---|---|
| Markdown | 阅读、整理、再编辑 | 纯文本，排版简单 |
| TXT | 快速查看 | 不带格式 |
| JSONL | 程序处理、分析 | 一行一条记录 |
| Agent Handoff | 交给另一个代理继续 | 保留交接所需结构 |
| 完整归档 | 长期留存、含附件 | 打包为压缩文件 |

## 导出步骤

1. 在左侧找到目标会话。
2. 打开会话操作菜单，选择“导出”。
3. 选择格式。
4. 在系统保存窗口中选择目录与文件名。
5. 确认保存。

生成时间取决于会话内容与附件数量。导出不会把归档自动放进项目资料库，也不会同步到另一台设备。

## 保管与分享

归档可能包含对话内容、文件信息和敏感上下文。

- 为文件选择易辨认的目录和名称。
- 分享前检查是否包含密钥、个人信息或内部资料。
- 按团队要求设置保存位置与保留期限。

导出后，应用侧栏仍保留原会话，可以继续使用。

## 导出失败时

| 现象 | 处理 |
|---|---|
| 保存窗口被取消 | 重新从菜单导出 |
| 目标目录不可写 | 换一个有写权限的目录 |
| 磁盘空间不足 | 清理空间后重试 |
| 系统保存服务失败 | 稍后重试，或换目录 |

会话仍可在应用内打开。不要因为一次导出失败就删除会话。

## 提示

- 需要交接时优先选择 Agent Handoff 或完整归档。
- 需要人工阅读时选择 Markdown。
- 导出成功后打开文件抽查，确认内容完整。

## 已知问题

- 导出的归档不会自动进入全局搜索或资料库。
- 不同格式包含的信息不完全相同。
