# 生成或编辑图片

**图片生成**（Image generation）是 Sunday 内置图片插件提供的能力：用文字生成新图片，或用参考图片进行编辑。

| 信息框 | |
|---|---|
| 类型 | 图片生成与编辑 |
| 插件 | imagegen |
| 工具 | generate_image |
| 数量 | 每次 1–4 张 |
| 参考图 | HTTP(S) 地址或工作区相对路径 |
| 前提 | 已启用工具并配置 API 地址 |

## 概述

图片生成需要可用的生图服务。没有配置 API 地址时，工具不会工作。<sup>[1][2]</sup>

生成结果是视觉草稿，不会自动证明其中的文字、数据或图形正确。

## 配置入口

1. 打开“插件”页面。
2. 找到 imagegen。
3. 打开配置面板。
4. 启用生图工具。
5. 填写 API 地址。
6. 如服务要求，填写 API Key 与模型名。
7. 保存并回到对话。

密钥保存在本机插件配置中。请妥善保护本机数据目录。

## 写提示词

说明：

- 主体。
- 环境。
- 构图。
- 风格。
- 要避免的元素。

例如：

> 生成一张横版城市书店插画，夜晚、暖色灯光、无文字。

对小字、图表或真实产品细节，不要假设生成内容准确。

## 提供参考图

不提供参考图时按文字生成。

提供参考图时：

| 来源 | 写法 |
|---|---|
| 网络图片 | 完整的 HTTP(S) 地址 |
| 本地图片 | 工作区内的相对路径 |

参考图找不到时，检查文件是否在当前工作区，或网址是否能公开访问。

## 数量与尺寸

- 每次可以生成 1 到 4 张。
- 数量超出范围会被限制在 1–4。
- 尺寸由工具参数与服务商支持能力共同决定。

## 常见问题

| 现象 | 处理 |
|---|---|
| 工具不在对话能力里 | 确认插件已启用、生图工具已打开 |
| 提示未配置 API | 补全 API 地址 |
| 服务超时 | 稍后重试 |
| API 报错 | 核对接口兼容性与模型名 |
| 参考图找不到 | 检查路径或公开访问性 |

## 提示

- 提示词先写主体与构图，再补风格细节。
- 一次生成多张时，用同一提示词比较差异。
- 需要准确文字时，生成后再人工校对或后期添加。

## 已知问题

- 生成结果依赖外部服务，服务不可用时工具失败。
- 图片中的文字与细节可能不准确。
