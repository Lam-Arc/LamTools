# Study 文本标记、解释和翻译

**Study 标记**（Study annotations）是学习工作区对一段文字进行标记、解释、询问或翻译的功能。标记会锚定原文字段和会话位置，之后可以在“标记”侧栏中重新定位。

| 信息框 | |
|---|---|
| 类型 | 文本标记与选区操作 |
| 位置 | Study 学习会话内容 |
| 操作 | 标记、解释、询问、翻译 |
| 标记位置 | 原文附近书签；右侧“标记”面板 |
| 作用范围 | 所选片段，周边文字仅用于消歧 |
| 是否影响 Notes | 否 |

## 概述

标记用于把学习材料中的关键句固定下来，并围绕它继续操作。它不修改原文，也不等同于笔记。<sup>[1][2]</sup>

## 选择一段内容

在 Study 学习会话里选中一段文字，打开右键或文本选择菜单，然后选择：

| 操作 | 行为 |
|---|---|
| 标记 | 保存该位置 |
| 解释 | 针对所选短句给出解释 |
| 询问 | 输入一个关于这段内容的问题 |
| 翻译 | 翻译选中的词或短语 |

示例：选中教材中的 “underlying assumption”，点“翻译”查看词义，或点“询问”问它在当前段落中的具体含义。

## 查看和管理标记

- 已标记内容会在原文附近显示书签标记。
- 标记也会出现在右侧“标记”面板。
- 点击引用可以跳回对应内容。
- 可以在面板中删除不再需要的标记。

解释或翻译可能在悬停时显示预览，也能重新打开完整卡片。

每次操作围绕所选片段；周边文字只用于消除歧义，不作为回答目标。

## 限制和排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 标记无法创建 | 选区为空 | 重新选择文字 |
| 标记无法跳回 | 原消息位置变化 | 重新定位原文 |
| 操作失败 | 所属会话不可用 | 回到有效会话 |
| 翻译质量不同 | 词典与模型两条路径 | 专业词要求结合学科解释 |
| Notes 里不能标记 | 标记只针对学习会话 | 使用 Notes 自己的锁定 |

翻译会先查询内置英汉词典；词库没有匹配时才询问模型。

遇到模型请求失败时，已有标记仍可保留。

## 提示

- 标记短句，不要标记整段，便于以后定位。
- 用“询问”处理语境问题，用“翻译”处理词义问题。
- 标记后把结论整理进笔记，避免只停留在书签。

## 已知问题

- 原文位置变化可能导致标记跳转失败。
- 标记不会自动进入笔记库。
