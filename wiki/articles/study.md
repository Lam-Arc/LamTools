# 学习工作区 Study

**Study** 是 Sunday 内置的学习工作区插件。它围绕课程、模块和知识点组织学习内容，并提供笔记、文本标记、词典、测验和知识图谱。

| 提供方式 | study 插件 |
| 结构 | 课程、模块、知识点 |
| 配套功能 | 笔记、标记、词典、测验、知识图谱 |
| 会话 | 独立的学习会话 |
| 掌握判定 | 以独立完成的测验结果为依据 |

## 概述

Study 共享 Sunday 的模型与常用工具，但使用独立的学习会话。它适合系统地学习一个学科，而不是只做一次问答。<sup>[1][2]</sup>

学习状态应以可核对的回答和证据为基础。看过讲解、复制答案或说“懂了”，都不会自动算作掌握。

## 知识结构与笔记

进入 Study 模式后，可以查看由课程、模块和知识点组成的知识网络，并按关系浏览：

- 前置关系。
- 包含关系。
- 相关关系。

笔记是可检索、可编辑的 Markdown 文档。底层区分原始资料、整理后的资源和笔记；笔记可以引用资源编号。用户锁定的笔记范围不会被助手覆盖。

新增课程结构时，先给出学科、课程和目标，再逐步补充节点与关系。

## 适合的任务

| 任务 | 示例 |
|---|---|
| 解释概念 | “用生活中的例子解释一次函数” |
| 依据材料作答 | “只根据这份讲义回答” |
| 整理笔记 | “把这一节整理成可复习的笔记” |
| 规划知识关系 | “列出这个模块的前置知识” |
| 出题测验 | “围绕本周内容出四道题” |

简单问题可以直接回答，不必每次都走“建图、讲解、考试”的完整流程。

需要最新或具体版本资料时，应要求搜索并检查原始来源。

## 进度和限制

- 独立完成且有依据的测验结果，才可以支持掌握状态。
- 图谱和笔记写入是持久变更，检查内容后再请求。
- 部分高级笔记整理能力可能属于未来功能，不应假设已启用。
- 课程或节点列表为空时，先选择或创建学习范围。

需要核验课程内容时，提供材料或明确来源。

## 提示

- 先说明基础和目标，再要求讲解深度。
- 一个重要难点比十个概念更适合作为一次学习的起点。
- 用测验检查是否真的会，而不是只看讲解是否听懂。

## 已知问题

- Study 是独立工作区，不会把学习记录混进普通会话。
- 掌握状态依赖测验覆盖范围，一次短测不能代表整门课程。
