# 成果库：找到工作产生的文件

**成果库**（Artifacts）是 Sunday 集中展示项目输入、中间产物和最终产物的列表。它帮助用户找到文件、核对结果，并把“记录”与“磁盘上的文件”分开看待。

| 信息框 | |
|---|---|
| 类型 | 成果清单 |
| 范围 | 当前项目 |
| 角色 | 用户资料、中间产物、产物 |
| 状态 | 正常、缺失、已移除 |
| 移除影响 | 只改变成果库状态，不删除磁盘文件 |
| 入口 | 项目成果面板、资料库相关资料入口 |

## 概述

成果库记录“这次工作产生了哪些文件”，并把它们按角色分类。它不是文件管理器，也不是聊天记录的替代品；它只展示已经登记的成果。<sup>[1][2]</sup>

先选中项目，才能查看对应成果。

## 成果与聊天回答的区别

模型在聊天中写出一段文字，并不表示已经保存成文件。

需要实际文件时，应在任务里说清保存位置和文件名，例如：

> 把整理结果保存为纪要.md，并告诉我位置。

完成后先找文件，再核对内容。不要仅凭聊天里显示了标题，就认为磁盘上存在同名文档。

## 筛选和查看

成果库支持：

- 按角色筛选。
- 按类型筛选。
- 按状态筛选。
- 显示或隐藏已移除的条目。

列表为空时，先检查当前项目和筛选条件，再刷新。点击条目会用系统默认应用打开文件；文件缺失时会给出提示。

## 角色与状态

| 角色 | 含义 |
|---|---|
| 用户资料 | 用户提供或上传的输入 |
| 中间产物 | 任务过程中生成的临时结果 |
| 产物 | 最终交付的文件 |

| 状态 | 含义 |
|---|---|
| 正常 | 记录存在，文件可访问 |
| 缺失 | 有记录，但磁盘文件被移动或删除 |
| 已移除 | 已从成果库隐藏，文件可能仍在 |

登记记录与磁盘文件不是同一个东西：有记录不保证文件一直存在，文件存在也不保证已经登记。

## 移除会删除文件吗

不会。移除只改变成果库中的状态，用于清理展示列表，不删除磁盘文件。<sup>[2]</sup>

如果需要释放磁盘空间，应另外处理真实文件，并明确告知 Sunday 要删除什么。想找回被隐藏的记录时，先开启“显示已移除”，不要为了恢复展示而重复生成同一文件。

## 提示

- 让任务明确写出保存路径和文件名，成果才容易核对。
- 删除磁盘文件与移除成果记录是两件事，不要混用。
- 列表为空时先看筛选条件，不要立刻重新生成。

## 已知问题

- 文件被外部移动后，记录仍在但打开会失败。
- 成果列表不会自动判断文件内容是否仍然正确。
