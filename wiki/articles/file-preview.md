# 分屏文件预览（实验性）

**分屏文件预览**（Split file preview）是 Sunday 桌面版在辅助分屏中直接查看工作区文件的能力。它把图片、音视频、PDF、Markdown、Word、Excel 和 PowerPoint 交给内置查看器，而不是用文本编辑器打开或交给外部应用；其他普通文本仍使用文本编辑器。<sup>[1][2]</sup>

| 信息框 | |
|---|---|
| 类型 | 文件查看 |
| 作用域 | 当前项目工作区内的文件 |
| 打开位置 | 辅助分屏的预览标签 |
| 支持格式 | 图片、音视频、PDF、Markdown、DOCX、XLSX、PPTX |
| 单文件上限 | 256 MB（Markdown 为 4 MB） |
| 当前状态 | 实验性功能，默认开启 |
| 关闭后的行为 | 预览类文件交回默认应用打开 |

## 概述

分屏文件预览解决的是“先看一眼”的问题：在聊天旁边打开一份表格、一张设计图或一个 PDF，不需要离开 Sunday，也不需要启动外部办公软件。预览标签与其他分屏标签一样参与拆分、拖动、聚焦和恢复，打开过的预览会随分屏布局保存在本机。<sup>[2][3]</sup>

预览只读取文件，不会改写原文件。Word、Excel 和 PowerPoint 的显示结果是只读渲染，不能在内置预览器里编辑；Markdown 可以从预览工具栏切换到文本编辑器修改。<sup>[2]</sup>

## 打开方式

文件默认按类型进入分屏：文本类扩展名进入文本编辑器，其余文件进入预览器。文件树、聊天中的文件引用、搜索结果、资料库以及文件右键菜单都使用同一条打开路径。<sup>[2][3]</sup>

已经存在预览标签时，新的文件会复用那块屏，而不是为每个文件重复拆分。用户也可以在右键菜单中选择“在分屏中打开”，明确要求使用分屏预览。<sup>[3]</sup>

| 入口 | 默认行为 |
|---|---|
| 文件树点击文件 | 按类型打开编辑器或预览器 |
| 聊天文件引用 | 按类型打开；预览不可用时回落到原小窗 |
| 全局搜索的文件结果 | 核实路径后按类型打开 |
| 资料库点击文件 | 按类型打开；关闭实验性开关后交给默认应用 |
| 文件右键菜单 | 提供“在分屏中打开”和“使用默认应用打开” |

## 支持的格式

文件类型由扩展名判断。相同扩展名使用同一种查看器，不以文件内容探测类型。<sup>[1]</sup>

| 类别 | 扩展名 | 查看方式 |
|---|---|---|
| 图片 | PNG、JPG、JPEG、GIF、WebP、BMP、ICO、SVG、AVIF、TIFF | 内嵌显示，可缩放 |
| 视频 | MP4、WebM、MOV、M4V、OGV、MKV、AVI | 内嵌播放器 |
| 音频 | MP3、WAV、OGG、OGA、M4A、FLAC、AAC、OPUS | 内嵌播放器 |
| PDF | PDF | 逐页渲染，可翻页和缩放 |
| Markdown | MD、MARKDOWN | 按正文排版渲染，可从工具栏切换到文本编辑器 |
| Word | DOCX | 保留段落、表格、页眉页脚与脚注的只读排版 |
| Excel | XLSX、XLSM | 按工作表显示单元格表格 |
| PowerPoint | PPTX | 文字大纲、备注与内嵌图片 |

其他普通文本与代码文件不在预览器范围内，仍进入文本编辑器，例如 JSON、YAML、TXT、Python、Rust、TypeScript 和 HTML。

## 预览器行为

### 图片与音视频

图片以适合预览区宽度打开，缩放比例以 100% 表示适合宽度，可以继续放大到 400% 或缩小到 25%。预览区可滚动，适合查看大图或长图。<sup>[2]</sup>

视频和音频使用系统网页视图的播放器。能否播放取决于文件编码：常见的 H.264 视频和 AAC 音频可以直接播放，MKV、AVI 等容器中的部分编码可能没有解码器。播放失败时，预览器会提示改用默认应用。<sup>[2][6]</sup>

### PDF

PDF 由内置阅读器逐页绘制，提供上一页、下一页与缩放。100% 表示适合预览区宽度，缩放范围是 50% 到 400%。翻页或连续缩放时，上一帧渲染会被取消，避免同一块画布重复绘制。<sup>[2]</sup>

需要密码的加密 PDF 不能打开；扫描版 PDF 可以正常显示页面图像，因为阅读器直接绘制页面，不依赖文字层。

### Markdown

Markdown 文件按正文排版显示，不再以源码形式占用编辑器。渲染与聊天正文使用同一套规则，支持标题、列表、表格、代码块、数学公式和 Mermaid 图；文档中的相对文件链接可以继续打开。<sup>[2][10]</sup>

预览工具栏提供编辑入口，点击后在同一分屏中打开文本编辑器。编辑器与预览共用同一份文件和草稿状态，修改后按文本编辑器原有的保存规则写回磁盘。<sup>[2][9]</sup>

Markdown 预览上限为 4 MB。超过上限或不是 UTF-8 文本时，预览器给出说明，需要改用文本编辑器或默认应用。

### Word 与 Excel

Word 文档以只读页面呈现，保留基本排版、表格、图片、页眉页脚和脚注。复杂分栏、文本框和部分字体效果可能与 Microsoft Word 有差异。<sup>[2]</sup>

Excel 文件按工作表分页显示，选中工作表后显示单元格网格。为避免超大表格拖慢界面，每个工作表最多显示前 500 行和前 60 列，超出部分不渲染，也不影响原文件。公式单元格显示读取到的计算结果，不显示公式本身。<sup>[2]</sup>

### PowerPoint

PowerPoint 没有完整的浏览器排版引擎，预览器采用折中方案：按页显示标题与文字段落，附上演讲者备注，并显示该页引用的内嵌图片。形状、动画、切换效果和精确位置不会还原。<sup>[2]</sup>

因此 PPTX 预览适合快速了解内容结构，不适合检查最终版式。需要核对排版时，应使用默认应用打开。

## 实验性开关

分屏文件预览在“设置 → 通用 → 实验性功能”中标记为实验性，默认开启。开关状态保存在本机，切换后立即生效，不需要重启应用。<sup>[4][5]</sup>

关闭开关后，预览类文件不再由分屏自动接管：文件树、资料库和搜索结果的默认打开会回到系统默认应用，聊天引用回落到原有的小窗预览。文本文件仍使用分屏文本编辑器，因为文本编辑不属于实验性预览。<sup>[3][4]</sup>

用户主动选择“在分屏中打开”时，预览器仍会打开，不受默认开关限制。该开关控制的是默认打开行为，不是彻底禁用预览器。<sup>[3]</sup>

## 边界与限制

| 边界 | 说明 |
|---|---|
| 工作区范围 | 与文本编辑器一样受当前项目目录限制 |
| 文件大小 | 超过 256 MB 拒绝预览，提示使用默认应用；Markdown 上限 4 MB |
| 只读 | 预览器不提供编辑与保存；Markdown 可切换到文本编辑器 |
| 旧版 Office | DOC、XLS、PPT 不在支持范围，提示改用默认应用 |
| 工作表规模 | 每个工作表最多显示 500 行 × 60 列 |
| PPTX 版式 | 不还原形状、动画和精确位置 |
| 编码支持 | 音视频依赖系统网页视图的解码能力 |

无法识别的文件类型仍会打开预览标签，但只显示说明和“使用默认应用打开”按钮，不会把二进制内容当作文本显示。<sup>[2]</sup>

## 提示

- 核对 Office 最终版式时，使用默认应用打开，不要只依赖内置预览。
- 需要修改 Markdown 时，点击预览工具栏的编辑按钮切换到文本编辑器。
- 大表格先确认工作表名称，再定位需要的行列；预览只显示前 500 行与前 60 列。
- 视频无法播放时先检查编码，而不是反复重新读取文件。
- 不需要内置预览时，可以在通用设置中关闭实验性开关，保持原有的默认应用工作流。
- 预览标签可以像其他分屏标签一样拖动、合并和关闭，关闭标签不会删除文件。

## 已知问题

1. PPTX 仅还原文字、备注和内嵌图片，复杂版式与动画缺失。
2. Excel 预览限制为每个工作表前 500 行、前 60 列。
3. MKV、AVI 等容器中的部分音视频编码可能无法在系统网页视图中播放。
4. 旧版 DOC、XLS、PPT 没有内置查看器。
5. 预览器不显示 PDF 表单、批注和 Word 修订的完整交互。
6. 实验性功能仍可能调整支持格式、上限与开关位置。
7. Markdown 超过 4 MB 或不是 UTF-8 时不能使用内置预览。
