# 界面外观

**界面外观**（Appearance）是 Sunday 中调整主题、明暗模式、内容密度和分区配色的设置集合。所有修改都会立即反映到当前界面，不需要重启应用。

| 信息框 | |
|---|---|
| 类型 | 外观设置 |
| 入口 | 设置 → 界面 |
| 明暗模式 | 跟随系统、浅色、深色、定时切换 |
| 内容宽度 | 560–1120 |
| 颜色节点 | 每个区域 1–8 个 |
| 可调区域 | 背景板 / 侧边栏、主界面、输入栏、控件 |

## 概述

外观设置分成两层：上层选择整体主题与明暗模式，下层在“高级调整”里修改密度、图标和具体区域的颜色。语言不在这一栏，而在“设置 → 通用”的“界面语言”中。<sup>[1]</sup>

## 主题与明暗模式

“外观”提供四种模式：

| 模式 | 行为 |
|---|---|
| 跟随系统 | 与操作系统的明暗设置一致 |
| 浅色 | 固定使用浅色 |
| 深色 | 固定使用深色 |
| 定时切换 | 按设定的开始时间自动切换 |

选择“定时切换”后，设置“浅色从”和“深色从”的开始时间；其余时间使用另一种模式。跨午夜的时段同样有效，例如浅色从 22:00 开始、深色从 08:00 开始。

下方的“预设颜色”只显示当前明暗模式对应的主题。点击预设会立即同步到界面；点击“恢复默认”可以回到默认主题。<sup>[1]</sup>

## 界面密度与内容宽度

展开“高级调整”后，可以修改：

- **界面密度**：控制内容区的信息密度。
- **内容宽度**：在 560 到 1120 之间调整，步长 20。

内容宽度影响的是内容区域，不是侧栏宽度。侧栏宽度由侧栏固定与窗口布局决定。

## 图标色彩

“图标色彩”控制过程行前的常规、运行和完成图标。等待与错误状态继续使用状态色，不随这项设置改变。

颜色框不接受输入时，可以使用颜色选择器，或输入有效的十六进制颜色值。

## 按区域调整配色

高级调整中的区域列表包括：

| 区域 | 说明 | 可调透明度 |
|---|---|---|
| 背景板 / 侧边栏 | 侧栏与背景板共用 | 否 |
| 主界面 | 聊天主内容区 | 是 |
| 输入栏 | 底部输入区域 | 是 |
| 控件 | 按钮等交互控件 | 是 |

点击区域会打开“详细调整”，可以编辑：

- 渐变颜色节点及其位置。
- 渐变角度。
- 文本颜色。
- 主界面、输入栏和控件的透明度。

每个区域至少保留一个颜色节点，最多八个。修改时会实时预览；文字与背景对比不足时，先看预览再决定是否保留。<sup>[2]</sup>

侧边栏使用“背景板 / 侧边栏”的配色，没有单独的侧栏颜色项。

## 常见问题

- **预设看起来变少了**：预设按明暗模式分别显示，切换当前模式后再查看。
- **只想改语言**：到“通用”分区选择“界面语言”，主题编辑器里没有语言开关。
- **颜色异常**：先用“恢复默认”确认是否为自定义颜色造成，再重新选择预设。
- **改了颜色后文字看不清**：调整文本颜色或渐变颜色，不要只靠提高对比度猜测。

外观设置不会更改会话、项目文件或模型配置。

## 提示

- 先用预设确定整体风格，再进入区域调整细节。
- 深色与浅色分别保存预设，切换模式不会互相覆盖。
- 调整透明度时优先保证文字可读，再追求视觉效果。

## 已知问题

- 不同版本提供的区域数量与可调项可能不同。
- 内容宽度只在提供滑块的版本中可调。
