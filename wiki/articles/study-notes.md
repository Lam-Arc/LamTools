# Study 笔记库

**Study 笔记库**（Study Notes）是学习工作区中可编辑的 Markdown 笔记集合。笔记以文件树和相互链接组织，适合长期整理学习内容。

| 信息框 | |
|---|---|
| 类型 | Markdown 笔记库 |
| 入口 | Study 左侧“笔记” |
| 组织方式 | 文件树、双向链接 |
| 链接写法 | `[[笔记标题]]`、`[[note:编号]]`、`[[node:编号]]` |
| 锁定 | 可锁定选中范围，避免助手覆盖 |
| 保存 | 手动保存 |

## 概述

笔记库解决“学到的东西放在哪里”。它使用常见的 Markdown 格式，不绑定某一种排版软件。<sup>[1]</sup>

助手可以在笔记助手会话中协助整理，但保存前应检查修改。

## 创建和编辑笔记

1. 在 Study 左侧选择“笔记”。
2. 查看目录并选择已有文档，或使用新建操作。
3. 在预览与编辑模式之间切换。
4. 写完后点击“保存”。

编辑器支持 Markdown 标题、列表、代码等格式。

离开有未保存草稿的笔记时，界面会让你选择保存、放弃或取消导航。

也可以在笔记页面切换到“对话”，让助手围绕当前文档提出整理建议。

## 链接和来源

正文可以使用三种链接：

| 写法 | 连接对象 |
|---|---|
| `[[笔记标题]]` | 另一篇笔记 |
| `[[note:编号]]` | 指定编号的笔记 |
| `[[node:编号]]` | 知识图谱中的节点 |

右侧关系区域展示笔记关联与反向链接。

笔记可以引用经过整理的资源；资源应能追溯到真实原始资料。来源缺失时，不要要求助手编造出处或用户原话。

## 锁定和冲突

在编辑器中选中一段文本，通过选择菜单锁定该范围，可以避免助手修改重叠内容。用户自己仍可编辑；要让助手修改，先解锁再请求。

多人或外部编辑导致版本冲突时：

1. 重新读取当前文档。
2. 比较变更。
3. 再保存。

不要盲目覆盖。

若只看到空树，刷新笔记列表，并检查当前 Study 插件是否提供笔记功能。

## 提示

- 用链接把复习笔记和知识节点连起来，比复制内容更耐用。
- 锁定关键段落，再让助手整理其他部分。
- 保存前预览，检查列表和标题层级。

## 已知问题

- 笔记不会自动与测验成绩同步。
- 外部编辑可能与当前草稿冲突。
