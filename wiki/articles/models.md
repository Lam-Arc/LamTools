# 模型与供应商

**模型与供应商**（Models and providers）是 Sunday 中配置模型连接、登记可用模型并选择默认模型的地方。供应商保存连接信息，模型保存具体能力与参数。

| 信息框 | |
|---|---|
| 类型 | 模型配置 |
| 入口 | 设置 → 模型与供应商 |
| 供应商字段 | 名称、服务地址、接口类型、API Key、适配参数 |
| 模型字段 | 模型 ID、显示名称、能力分类、上下文窗口、最大输出、推理预算 |
| 默认模型 | 模型行上的“设为预设首选” |
| 单次选择 | 聊天输入框的模型菜单 |

## 概述

一次模型请求需要两层信息：

- **供应商**：请求发到哪里，用什么接口和密钥。
- **模型**：请求里写哪个模型标识，它支持多长的上下文、多少输出和什么推理能力。

只有供应商配置正确，模型标识也正确，请求才会成功。连接成功但生成失败，通常是模型 ID 或能力参数与服务端不一致。<sup>[1][2]</sup>

## 添加供应商

在“模型与供应商”页点击“新增供应商”，填写：

| 字段 | 作用 |
|---|---|
| 名称 | 在列表中辨认这个连接 |
| 服务地址 | 接口的基础地址 |
| 接口类型 | 请求使用的协议 |
| API Key | 调用凭据 |
| 高级适配 JSON | 服务端要求的特殊参数 |

也可以从官方模板开始，再按服务商要求修改。编辑已有供应商时，密钥字段留空表示保留现有密钥。

保存后供应商会出现在列表中，可以搜索、编辑或删除。删除前确认没有模型仍依赖这个连接。

## 登记模型

选中供应商后点击“新增模型”，填写：

- **模型 ID**：必须与服务端实际接受的标识一致。
- **显示名称**：选填，留空时使用模型 ID。
- **能力分类**：用于界面分组与选项展示。
- **支持推理、推理等级、推理预算**：决定思考模式菜单的内容。
- **上下文窗口、最大输出**：用于估算容量与限制输出。
- **高级适配 JSON**：只有明确知道服务端要求时才修改。

模型能力会直接影响界面可选项。填错窗口或推理能力，可能导致请求被拒绝，或界面显示与实际能力不符。

## 默认与当前选择

| 选择 | 作用范围 |
|---|---|
| 设为预设首选 | 新会话默认使用的模型 |
| 聊天输入框的模型菜单 | 当前运行使用的模型 |

切换当前模型后，思考模式与输出限制等选项会按新模型声明刷新。已经完成的消息不会改变。

同一会话中频繁切换模型，会让请求参数变化，可能使缓存前缀失效。

## 连接失败时

按以下顺序检查：

1. 供应商是否存在且已保存。
2. API Key 是否正确、是否过期。
3. 服务地址是否包含正确的路径。
4. 接口类型是否与服务端一致。
5. 模型 ID 是否真实存在。
6. 网络或代理是否阻止访问。

连接错误时，保留服务端返回的信息，不要只记录“失败”两个字。

## 密钥安全

- 不要把密钥粘贴到聊天、项目规则或截图中。
- 不要写进 `AGENTS.md` 或记忆文件。
- 怀疑泄露时，先在服务商处吊销，再更新配置。

本地保存的密钥由应用管理；共享截图或导出配置前先检查是否包含密钥。

## 提示

- 先用一个模型完成简单问答，再添加更多供应商。
- 模型 ID 从服务商文档复制，不要凭记忆手写。
- 修改模型能力后，用一轮小任务验证思考模式与输出限制。

## 已知问题

- 供应商模板不保证账号有权限调用其中的全部模型。
- 模型能力字段由用户填写，填错不会自动被服务端纠正。
