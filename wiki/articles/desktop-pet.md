# 桌宠 Emotion Ball

**桌宠**（Emotion Ball）是 Sunday 桌面版内置的一个小型陪伴窗口。它连接自己的专属会话，可以直接接收消息、文件和审批。

| 信息框 | |
|---|---|
| 类型 | 桌面陪伴窗口 |
| 提供方式 | emotion-ball-pet 内置插件 |
| 会话 | 独立的 Core 会话 |
| 可处理 | 消息、拖入文件、提问、工具审批 |
| 审批选项 | 允许一次、拒绝 |
| 与主聊天 | 不是同一个输入框 |

## 概述

桌宠是主应用之外的另一个入口，适合在桌面角落快速发起一件事或处理一条等待中的审批。<sup>[1]</sup>

它使用单独的 Core 会话，不是当前主聊天会话的另一个输入框。回复、运行状态和等待事项都显示在桌宠窗口里。

## 打开并发送消息

1. 在 Sunday 桌面端的命令入口选择“桌宠”。
2. 桌宠会显示为独立窗口。
3. 点击图标展开面板。
4. 在“给桌宠发送消息”输入框中写任务并发送。

任务完成时会显示结果卡片；运行中也会显示状态。

## 拖入文件

把文件拖到桌宠窗口，会出现“已添加文件”卡片。

处理步骤：

1. 检查文件名。
2. 移除不需要的文件。
3. 输入可选的处理指令。
4. 点击“发送”。

例如：

> 读取这些会议记录，按日期整理行动项。

发送前，桌宠会把附件上传到自己的会话并作为消息发送。上传失败时，卡片会保留文件和指令，便于修正后重试。

拖放导入失败时，重新拖入文件，并确认桌宠窗口仍然打开。

## 回答和审批

桌宠会显示 Core 会话提出的问题：

- 可以点选选项。
- 也可以输入回答后提交。

工具审批卡会说明待执行的命令或工具，可以选择“允许一次”或“拒绝”。需要更多背景时先看详情。

提交失败时，卡片会显示错误并允许重试。

批准只针对当前请求。未核对目标、参数和影响前，不要点击批准。

若提示无法连接，先确认 Sunday 主程序正在运行，再关闭并重新打开桌宠。

## 提示

- 把桌宠当作独立会话，不要期待它继承主聊天的上下文。
- 审批前先看命令与参数。
- 拖入多个文件时，在指令里说明每个文件的用途。

## 已知问题

- 桌宠会话与主聊天会话相互独立。
- 上传失败时不会自动重试，需要手动发送。
