# 连接外部工具（MCP）

**MCP**（Model Context Protocol）是 Sunday 连接外部工具服务的协议。Sunday 通过查询入口读取服务器、工具说明与参数，通过命令通道执行具体操作；外部工具不再逐个加入模型的工具清单。<sup>[1][2]</sup>

| 信息框 | |
|---|---|
| 类型 | 外部工具连接 |
| 查询 | 服务器、工具列表、参数说明 |
| 执行 | 本机命令通道 |
| 默认操作等级 | 3 级 |
| 插件声明 | 可声明服务器、工具与具体动作的等级 |
| 当前版本 | 0.3.22-a3 内部测试版 |

## 概述

MCP 服务可提供网页访问、文件处理、专用数据源等能力。服务需来自已经配置的来源或已启用的插件，实际能力取决于服务本身。安装插件不等于对应服务已成功连接。<sup>[2][3]</sup>

技能说明任务的做法，插件可提供界面、配置和服务，MCP 负责与外部服务交换工具请求。<sup>[1][3]</sup>

## 查询与执行

### 查询入口

MCP 查询入口只负责列出服务器、列出工具和读取参数说明。工具的默认等级及按动作区分的等级可随参数说明一并查看。查询本身为 1 级，不执行被查询的工具。<sup>[1][4]</sup>

### 命令调用

具体调用统一经过本机命令通道。例如以下命令请求已配置的 B 站服务进行搜索：

```text
core mcp call --tool mcp__bilibili__search --arguments '{"keyword":"本地模型","days":3}'
```

这类请求仍按 MCP 操作的实际等级判定，不会因为写成命令就变成普通构建命令的等级。参数直接解析，不进行 shell 变量展开或命令替换。旧会话中遗留的 MCP 激活、直接调用入口会被拒绝，并提示使用命令通道。<sup>[1][4]</sup>

## 权限等级

| 情形 | 基础等级 | 处理 |
|---|---|---|
| 未声明等级的 MCP 调用 | 3 | 询问、自动模式需要确认 |
| 插件声明的只读查询 | 可声明为 1 | 在能力范围内可自动执行 |
| 插件声明的普通写入 | 可声明为 2 | 询问模式确认，自动模式可放行 |
| 硬禁止的操作 | 0 | 所有模式均拒绝 |

等级还需与当前能力上限、免问线和已保存的信任一起判断。“完全访问”自动放行到 3 级，但不能解除硬禁止，也不会自动扩大只读能力上限。完整规则见[审批](approvals.md)。<sup>[4][5]</sup>

## 插件预声明

插件可在随插件安装的 MCP 配置中预先声明服务器默认等级、工具等级，或进一步按工具的动作分级。未声明的服务器默认 3 级，工具继承服务器默认等级；特定工具与动作的声明优先。<sup>[2][6]</sup>

```json
{
  "mcpServers": {
    "example": {
      "command": "example-server",
      "level": 3,
      "toolLevels": {
        "search": 1,
        "save": 2,
        "delete": 3,
        "records": {
          "default": 3,
          "actions": { "list": 1, "update": 2 }
        }
      }
    }
  }
}
```

声明必须是非负整数。服务端返回的说明或提示不会自行降低等级；执行时以安装配置和实际动作参数重新判断。<sup>[1][6]</sup>

## 连接与后台任务

连接按需建立，由所属运行回收。后台值班轮使用独立的连接和精确工具范围；将执行放进命令通道，不代表受限后台任务可以执行任意系统命令。审批后继续运行时，工具范围、规则和已消耗预算保留。<sup>[1][7]</sup>

插件依赖安装在其保留的数据区域，本机路径在使用时解析；升级无需把发布配置改写成本机绝对路径。<sup>[2][8]</sup>

## 连接排查

| 现象 | 检查内容 |
|---|---|
| 找不到服务器 | 插件是否启用、名称是否准确、配置是否有效 |
| 找不到工具 | 查询当前工具列表，核对完整名称 |
| 参数不匹配 | 重新读取参数说明 |
| 等待审批 | 当前动作等级、能力上限与权限预设 |
| 启动失败 | 服务依赖、启动方式与错误记录 |
| 认证失败 | 凭据是否配置或过期 |

## 提示

- 连接验证宜先使用已声明的只读操作。
- 工具等级应与真实行为一致，不宜仅根据名称判断。
- 需要长期放行某个精确操作时，可在审批中选择“批准并信任”；保存的信任可在权限设置中撤销。

## 已知问题

1. 第三方服务的可用性取决于其依赖、网络与认证状态。
2. 操作等级控制调用前的授权，不是第三方服务代码的文件系统沙箱。
3. 内部测试版的配置与行为可能随后续测试调整。
