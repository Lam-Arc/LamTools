# 主题填充与玻璃材质

**主题填充与玻璃材质**（Theme fill and glass material）是 Sunday 界面外观中控制四个区域底色的两个独立设置。填充决定区域里放什么内容（纯色、渐变或图片），玻璃材质决定该区域的表面是否换成玻璃；玻璃使用填充的颜色、渐变或图片作为着色，而不是替代填充。<sup>[1][2]</sup>

| 信息框 | |
|---|---|
| 类型 | 外观设置 |
| 入口 | 设置 → 界面 → 高级调整 |
| 填充方式 | 纯色、渐变、图片 |
| 玻璃档位 | 关闭、高透玻璃、低透玻璃 |
| 可调区域 | 背景板 / 侧边栏、主界面、输入栏、控件 |
| 图片格式 | PNG、JPEG、GIF、WebP、AVIF、SVG |
| 单张图片上限 | 1.5 MB |
| 保存方式 | 浅色与深色主题分别保存 |
| 当前状态 | 已提供填充与玻璃；图片填充暂不提供透明度 |

## 概述

界面被分成四个区域：背景板 / 侧边栏、主界面、输入栏、控件。每个区域的“详细调整”分成两个独立块：填充与玻璃材质。

填充只描述区域里放什么内容，玻璃材质只描述这个区域的表面是什么材质。两者分开的原因是玻璃并不是一种颜色：它可以搭配任意一种填充，也可以随时关闭而不丢失原来的颜色、渐变或图片。关闭玻璃后，区域恢复成普通填充，透明度重新由填充自己控制。<sup>[1]</sup>

## 填充

填充有三种方式，同一时间只启用一种。

### 纯色

区域使用一个颜色，并提供透明度滑杆，取值范围为百分之十到百分之百。纯色是默认填充，也是其他填充方式在内容缺失时的兜底：图片尚未选择时，区域仍然使用这个颜色。

### 渐变

渐变使用一至八个颜色节点，每个节点带位置百分比，另有一个零到三百六十度的角度。节点按位置排序后参与渲染；所有节点颜色相同时，结果会收成一个节点，按纯色呈现。

渐变同样提供透明度滑杆。主界面、输入栏和控件可以调整透明度；背景板 / 侧边栏固定为不透明。

### 图片

图片填充提供选择图片、清除、适应方式和底色四项。

| 项目 | 可选值 | 说明 |
|---|---|---|
| 适应方式 | 铺满、完整显示、平铺、拉伸 | 决定图片如何铺进区域 |
| 底色 | 任意颜色 | 透明图片会透出底色，玻璃开启时作为玻璃的着色 |
| 文件格式 | PNG、JPEG、GIF、WebP、AVIF、SVG | 按文件内容识别，不依赖扩展名 |
| 动图 | GIF、动态 WebP、APNG | 按原始数据保存，播放不受影响 |
| 单张大小 | 不超过 1.5 MB | 超过时拒绝导入并给出提示 |

图片铺在区域的主表面上。区域内的卡片、输入框和列表继续使用底色，不会各自重复铺一张图，因此同一张背景图不会在界面里被切成很多块。<sup>[1][3]</sup>

图片填充不提供透明度滑杆，原因见[已知问题](#已知问题)。

## 玻璃材质

玻璃材质是三档偏好：关闭、高透玻璃、低透玻璃，默认关闭。它不是一种填充类型，而是一层表面处理。

### 高透与低透

开启玻璃后，区域主表面的底色改由材质浓度决定：高透玻璃按百分之二十二着色，低透玻璃按百分之五十八着色，并叠加背景模糊、饱和度、亮度与对比度的轻微调整。高透更接近透明，低透更实、更接近磨砂玻璃。两档使用同一套模糊参数，区别只在着色浓度。<sup>[2]</sup>

模糊、两像素边框、阴影和底部折射属于共享的玻璃底座，不是每张卡片各自声明的。菜单、悬浮卡和设置弹层使用同一份底座，只是着色更轻：高透约百分之十六，低透约百分之四十；不支持背景模糊的环境会自动提高着色比例作为回退。<sup>[7]</sup>

玻璃面本身不叠加淡入或位移动画。部分桌面运行环境会在动画期间重建背景采样，导致模糊暂时或彻底消失；需要淡入时，把动画放在玻璃内部的内容层上。右侧栏的悬浮卡采用这种做法：玻璃面保持稳定，淡入由内部内容完成。<sup>[8]</sup>

### 与填充叠加

玻璃开启时，填充的颜色、渐变或图片就是玻璃的着色内容：

| 填充 | 玻璃开启后的表现 |
|---|---|
| 纯色 | 该颜色按材质浓度变成半透明着色 |
| 渐变 | 各颜色节点按材质浓度着色，渐变关系保留 |
| 图片 | 图片上方覆盖一层同色薄雾，图片仍按原样播放动图 |

玻璃开启时，颜色选择器直接可用，所选颜色就是玻璃底色；高透或低透只决定这层底色的浓度。填充的透明度滑杆会收起，关闭玻璃后恢复。<sup>[1]</sup>

背景板 / 侧边栏开启玻璃时，窗口底板会让出底色，玻璃后面会透出桌面而不是同一块实色。这时需要留意背景板文字与桌面内容的对比度。<sup>[2][6]</sup>

### 叠层与可读性

玻璃不会把背后的内容盖住，只会模糊并着色。字号大、对比强的文字即使被模糊，仍可能看出轮廓，形成“鬼影”；这与模糊半径关系不大，更多取决于底色浓度和前后景对比。

| 情况 | 结果 |
|---|---|
| 高透玻璃压在正文上 | 正文轮廓明显，容易干扰阅读 |
| 低透玻璃压在正文上 | 正文被压暗，通常只剩淡淡影子 |
| 两层玻璃叠加 | 上层只能模糊下层的结果，下层文字不会自动消失 |
| 玻璃后是纯色或低对比内容 | 基本看不出穿透 |

因此菜单、右键菜单和设置弹层默认使用低透。设置弹层保留原本的底色，只补一层模糊来压住后面透出的文字；如果底色本身很透，仍然需要提高底色浓度或改用低透。<sup>[9]</sup>

## 四个区域

四个区域共用同一套填充与玻璃设置，但玻璃滤镜落在各自的主表面上。

| 区域 | 覆盖范围 | 玻璃开启后的主表面 |
|---|---|---|
| 背景板 / 侧边栏 | 外壳底色、侧栏与会话列表 | 窗口底板 |
| 主界面 | 聊天主内容区 | 主卡 |
| 输入栏 | 底部输入区域与文本输入 | 输入栏卡片 |
| 控件 | 按钮、选择器等交互控件 | 主要填充控件 |

控件区的图片与玻璃只落在主要填充控件上，例如发送按钮与主要操作按钮；菜单、下拉和行内小控件继续使用控件底色。<sup>[5]</sup>

## 保存与迁移

浅色与深色主题分别保存填充、玻璃和图片设置，切换明暗模式不会互相覆盖。

应用预设会把玻璃恢复为关闭，因为预设本身不包含玻璃设置；填充按预设的颜色节点推断，单节点为纯色，多节点为渐变。

旧版本曾把“玻璃”当作一种填充方式。这类设置会自动迁移成“纯色填充 + 高透玻璃”，玻璃偏好也会保护该主题不被误判为旧默认主题而重置。<sup>[2][4]</sup>

## 提示

- 先确定填充内容，再决定是否开启玻璃；玻璃只是材质，不会改变填充本身。
- 玻璃开启后想调整色调，直接改填充的颜色或渐变的颜色节点；图片填充可以改底色。
- 图片搭配玻璃时，想看清图片本身用高透，想得到更浓的玻璃色用低透。
- 背景板玻璃会透出桌面，文字对比度不足时优先调深底色或改用高透。
- 渐变节点两到三个通常已经足够，节点越多，玻璃下的过渡越难辨认。
- 浮层压在文字上时优先选低透，不要只靠加大模糊。
- 玻璃下还有另一层玻璃时，先看下层是否有文字；有文字就用低透或更实的底色。

## 已知问题

- **图片填充没有透明度滑杆**：透明度在实现上只作用于颜色，图片是背景层，无法在 CSS 里单独变得半透明。因此图片模式隐藏了滑杆，避免出现拖动后没有任何变化的控件。需要图片淡出的效果时，暂时只能用纯色或渐变模拟。
- 玻璃模糊依赖渲染环境支持背景模糊；不支持时仍会着色，但不会出现模糊。
- 叠层玻璃仍可能透出下层文字的轮廓，尤其在高透叠高透、前后景对比很强时；目前没有自动拦截。
- 保存或发布前没有针对玻璃可读性的检查，无法提示某块玻璃是否压住了正文。
- 图片以原始数据保存在界面偏好中。单张上限为 1.5 MB，多张大图可能触及浏览器本地存储上限；保存失败时设置只在当前会话生效。
- 图片与玻璃叠加时只增加同色薄雾，不对图片本身做磨砂处理。
- 控件区的图片与玻璃不覆盖菜单、下拉等小浮层。
- 部分较早的浮层仍使用半透明底色而不是共享玻璃底座，叠在文字上时穿透更明显。

## 历史

- **2026 年 10 月**：区域配色拆成“填充”和“玻璃材质”两个独立节点；填充新增图片与动图支持；旧版“玻璃填充”自动迁移为“纯色 + 高透玻璃”。
- **2026 年 10 月 30 日**：玻璃模式开放底色选择；设置弹层保留原底色并补上模糊；右侧栏悬浮卡把淡入动画移到内层，避免模糊失效；共享玻璃底座补齐边框与折射。
