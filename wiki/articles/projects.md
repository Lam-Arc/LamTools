# 项目

**项目**（Project）是 Sunday 对一个本机工作目录的登记项。它把工作目录、项目规则和相关会话放在一起，适合按代码库或工作主题管理长期工作。

| 信息框 | |
|---|---|
| 类型 | 工作容器 |
| 入口 | 左侧项目区：新建项目、选择已登记项目 |
| 对应位置 | 本机工作目录 |
| 关联内容 | 会话、项目规则、子代理配置 |
| 删除影响 | 项目及其会话记录一并移除 |

## 概述

项目不是复制一份目录，而是把已有目录登记到 Sunday 中。文件仍然在原来的位置，工具也从那个目录开始工作。项目解决的是“这次工作属于哪个主题、用哪套规则、会话放在哪里”。<sup>[1]</sup>

如果只是一次性提问，不需要项目规则或会话分组，可以直接使用未归属项目的会话。

## 创建与登记

创建项目时：

1. 选择本机目录。
2. 设置名称、图标和颜色。
3. 保存后，Sunday 会建立一个新会话并切换过去。

已有项目可以通过“选择已登记项目”加入侧栏。目录必须存在，并且当前用户有访问权限；路径无效时，后续文件操作会失败。

## 会话与侧栏分组

项目会在会话侧栏中分组显示：

- 每个项目默认展示最近的若干会话。
- 点击“展开另外…个会话”可以看到更早的记录。
- 常用的项目可以固定，也可以折叠整个分区。
- 项目菜单提供重命名、设置和删除。

会话归属于项目，不等于会话与目录同名。打开已有项目时，仍要确认当前选中的项目正确。<sup>[1][2]</sup>

## 项目设置与规则

打开项目菜单并进入“项目设置”，可以调整项目资料，并编辑项目级的 `AGENTS.md`。

项目规则会叠加在全局规则之上，用来记录这个项目的构建方式、代码约定和注意事项。只适用于单次任务的内容不应写成长期规则，否则每次请求都会携带它。

项目设置中的子代理分区还可以配置该项目范围内的委派偏好。保存失败时，先确认目录仍然可写，再刷新设置。<sup>[3]</sup>

## 删除与路径变化

删除项目会连同该项目的会话记录一起从应用数据中移除。执行前应确认目标项目，重要记录先导出或备份。

如果项目目录被移动、重命名或所在磁盘不可用：

- 已有会话记录仍可能存在。
- 文件、命令和规则相关功能会受限。
- 重新选择有效目录后可以继续使用。

## 提示

- 为不同主题建立不同项目，不要把无关工作堆在同一个目录。
- 项目规则只写长期有效的约定，临时要求放在当次对话里。
- 删除项目不可撤销，先确认会话是否需要保留。

## 已知问题

- 删除项目不会删除磁盘上的原始文件，只移除应用内的项目与会话记录。
- 目录被外部移动后，需要重新指定路径。
