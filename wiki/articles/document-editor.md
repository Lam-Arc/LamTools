# 编辑方案和记忆文档

**文档编辑器**（Document editor）是 Sunday 中编辑方案、记忆和规则文档的共用界面。它直接编辑 Markdown 原文，并提供工具栏与预览模式。

| 信息框 | |
|---|---|
| 类型 | 文档编辑器 |
| 适用内容 | 方案、记忆、项目规则 |
| 存储格式 | Markdown |
| 模式 | 编辑、预览 |
| 常用按键 | Enter 续列表、Tab 缩进、Ctrl+B 加粗 |
| 保存 | 由所在页面提供，预览不等于保存 |

## 概述

方案、记忆和项目规则都以文本形式保存。编辑器让用户直接修改这些文本，而不是通过表单逐项填写。

它适合结构化文字，不是完整的办公排版软件，也不能直接修改任意格式的办公文件。<sup>[1]</sup>

## 怎样编辑

进入编辑后，看到的是 Markdown 原文。Markdown 用少量符号表示排版：

- 标题前加井号。
- 列表前加短横线。
- 链接写成方括号加圆括号。

不会写这些符号也可以先写普通段落，再用工具栏套用格式。

## 工具栏

工具栏通常包含：

- 标题层级。
- 加粗、斜体。
- 有序列表、无序列表、清单。
- 引用、代码。
- 链接。

部分操作需要先选中文字；没有选中时，按钮可能不可用，或只插入标记。先选中目标内容再操作，最容易看懂变化。

## 编辑与预览

| 模式 | 用途 |
|---|---|
| 编辑 | 修改原文 |
| 预览 | 检查最终排版 |

两种状态显示同一份内容。切换预览不会保存，仍要使用所在页面的保存动作。

例如，把一份执行方案写成“目标、准备、步骤、验收”四个二级标题，再用清单列出检查项。预览能帮助发现标题层级混乱、列表没有分开或链接写错。

## 快捷操作

| 按键 | 行为 |
|---|---|
| Enter | 延续当前列表 |
| Tab | 增加缩进 |
| Shift+Tab | 减少缩进 |
| Ctrl+B | 加粗 |

这些按键只在编辑器获得焦点时生效；在聊天输入框中含义不同。<sup>[2]</sup>

## 保存与失败

离开页面前确认修改已经保存。保存失败时：

1. 先把未保存正文复制到安全位置。
2. 再检查连接、权限或文件是否被占用。
3. 不要因为预览里能看到，就认为重启后仍然存在。

## 提示

- 先写结构，再补内容，比边写边调格式更快。
- 长文档按标题分段，预览时更容易发现层级问题。
- 重要修改前先复制一份原文。

## 已知问题

- 预览只反映排版，不检查链接是否可访问。
- 编辑器不处理复杂表格、批注和修订。
