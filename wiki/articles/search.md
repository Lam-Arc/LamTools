# 全局搜索

**全局搜索**（Global search）是 Sunday 跨项目查找任务、插件条目和文件的入口。它把分散的结果按类别集中展示，并可以直接跳转到对应位置。

| 信息框 | |
|---|---|
| 类型 | 全局检索 |
| 入口 | 侧栏“搜索”或 Ctrl+K |
| 结果分类 | 全部、任务、插件、文件 |
| 额外分组 | Study（仅在学习会话中出现） |
| 范围 | 已登记的项目与会话数据 |
| 打开方式 | 在当前窗口内跳转，不新建会话 |

## 概述

全局搜索把原先分散的入口归成四类：任务、插件、文件，以及学习会话中的 Study 分组。它的价值在于“记得有这件事，但忘了在哪”，而不是替代项目内的文件搜索。<sup>[1][2]</sup>

侧栏顶部的“搜索项目和会话”只过滤当前列表，不是全局搜索。

## 打开与选择范围

点击侧栏“搜索”或按 Ctrl+K 打开搜索页。Ctrl+K 在输入框内同样有效，不会丢失当前草稿。

输入关键词后，可以在“搜索范围”标签之间切换：

- **全部**：按类别分组展示。
- **任务**：任务标题，以及启用检索时的消息级命中。
- **插件**：插件、技能、钩子，命中后打开插件面板的对应分区。
- **文件**：文件名、文件内容，以及已索引文档的语义命中。

空查询时，页面展示可用快捷入口。

## 结果分类

| 分类 | 包含内容 | 打开后 |
|---|---|---|
| 任务 | 会话与消息命中 | 打开对应会话，并尝试定位到相关消息 |
| 插件 | 插件、技能、钩子 | 跳到插件面板的对应分区 |
| 文件 | 文件名与内容命中 | 交给系统默认应用打开 |
| Study | 节点、笔记、会话 | 跳到学习工作区中的对应位置 |

Study 分组只在学习会话里出现，作为“全部”下的独立分组。

## 打开结果

- 任务命中会打开会话，并尽量滚动到相关消息。
- 文件命中会调用系统默认应用打开；路径失效时会提示打开失败。
- 插件命中会进入对应分区，而不是打开一篇说明页。

搜索结果依赖当前索引和可访问文件。刚生成的方案或资料，要等任务结束后再刷新搜索。

## 快捷操作

搜索页会列出常用动作，例如新建会话、打开已登记项目或切换导航入口。只有界面上实际列出的快捷键才应当视为可用，不要凭记忆套用其他组合键。

清除按钮会重置查询；返回会回到聊天，不会删除任何数据。

## 限制

| 限制 | 说明 |
|---|---|
| 不搜索未登记项目 | 只覆盖应用已知的项目与会话 |
| 不创建缺失文件 | 找不到就是找不到 |
| 文件内容依赖索引 | 未索引的内容可能只按文件名命中 |
| 路径失效 | 文件被移动后打开会失败 |

## 提示

- 记得关键词但忘了项目时，先用“全部”再逐步缩小分类。
- 找文件内容时优先用文件名或独特短语，避免常见词。
- 打开结果前先看分组与来源，避免同名文件混淆。

## 已知问题

- 语义检索依赖额外组件；未启用时，文件搜索主要按名称与字面内容匹配。
- 刚完成的任务可能还未进入索引，需要稍后刷新。
