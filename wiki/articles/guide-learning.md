# 实用教程：学会一个知识点

**学习教程**（Learning walkthrough）是一套围绕单个知识点的完整练习路径：说明目标与基础、听讲解、做独立练习、留下笔记，最后判断是否真的学会。

| 信息框 | |
|---|---|
| 类型 | 实践教程 |
| 适用场景 | 学会一个可描述清楚的小知识点 |
| 前置条件 | 学习插件已启用、模型可正常回答 |
| 步骤数 | 4 |
| 相关功能 | Study、笔记、测验、知识图谱 |
| 建议时长 | 一次 20–40 分钟 |

## 概述

一次学习最好围绕一个能说清楚的小目标，而不是一句“教我整个学科”。<sup>[1][2]</sup>

开始前先读[学习工作区 Study](study.md)，了解可用范围与限制。

## 先说明目标和基础

示例：

> 我知道一元一次方程，但没学过二元一次方程组。请用两个未知数的生活例子解释它要解决什么，先不要直接给一大段公式。

也可以提供教材版本、课件或原始题目，让讲解有明确依据。

模型的解释应与基础相符。看不懂时，直接指出卡在哪一步，例如：

> 我不懂为什么两式相减可以消掉一个未知数。

这比“再讲简单一点”更容易得到针对性说明。

## 做一道独立练习

学完后要求一道同类题：

1. 先自己作答。
2. 再让 Study 核对步骤。
3. 需要时求助，但记录自己用了多少提示。

受到提示的表现与完全独立完成不同。不要把看过答案后的复述当成已经掌握。

需要更完整检查时，使用[测验](study-exams.md)。提交前检查答案是否清楚，尤其是图片中的数字和符号。评分不合理时，指出具体题目和推导，请它复核依据。

## 留下以后有用的东西

要求整理一份短笔记，包含：

- 概念。
- 易错点。
- 一个例子及其解释。

检查后保存到对应学习笔记，而不是把整段对话原样复制。

相关知识点之间的前置关系可以放进[知识图谱](study-knowledge-map.md)，帮助下一次决定先学哪里。

## 怎样判断这次学到了

尝试不看提示完成三件事：

1. 解释概念。
2. 选择方法。
3. 做一道新题。

隔一段时间再复习一次。知识图谱中的状态和一次测验成绩都只是学习证据，不等于对能力的最终评价。

学习材料有争议或版本差异时，要求标明来源。

## 常见偏差

| 偏差 | 调整 |
|---|---|
| 讲解太长，抓不住重点 | 缩到一个具体问题 |
| 听懂了但不会做 | 增加独立练习 |
| 做题依赖提示 | 把提示与独立完成分开记录 |
| 笔记只是复制对话 | 要求写成概念、易错点、例子三段 |

## 提示

- 先说明“已经会什么”，再说明“卡在哪里”。
- 一个难点比十个概念更适合作为一次学习的起点。
- 把易错点写进笔记，复习时优先看它。

## 已知问题

- 讲解与测验质量受模型能力影响。
- 一次测验只覆盖抽样范围。
