# 资料库

**资料库**（Library）是 Sunday 集中浏览项目资料、记忆、方案和内置 Wiki的全屏入口。它把四类内容放在同一个页面里，用顶部分区切换。

| 信息框 | |
|---|---|
| 类型 | 资料入口 |
| 入口 | 应用侧栏“资料库” |
| 分区 | 资料、记忆、方案、Wiki |
| 呈现方式 | 全屏工作区 |
| 依赖 | 多数操作需要先选择项目 |

## 概述

资料库解决“东西放在哪里”的问题。它不替代聊天，也不切换会话；打开资料库后，原来的项目和会话仍然保留，返回聊天即可继续。<sup>[1]</sup>

资料库以全屏区域打开，按返回或 Esc 退出。

## 四个分区

| 分区 | 内容 | 来源 |
|---|---|---|
| 资料 | 项目中进出的文件 | 用户上传、中间产物、最终产物 |
| 记忆 | 项目档与全局档的记忆 | 项目记忆与全局记忆 |
| 方案 | 项目“方案/”下的计划文档 | 方案插件 |
| Wiki | 随当前应用版本内置的只读说明 | 版本安装包 |

分区切换只改变资料库显示的内容，不会切换聊天会话。

## 资料与成果

“资料”分区展示项目文件、输入资料和运行产生的成果。可以通过界面提供的操作上传文件。

上传会：

1. 把文件放入项目的资料目录。
2. 在成果库中登记为输入成果。
3. 在会话结束后触发列表刷新。

查看条目前先确认它属于当前项目，避免把资料放错工作区。打开本机文件会交给系统默认应用。

## 记忆与方案

- **记忆**：先列项目这一层，再进入具体档位。可以查看项目档与全局档。
- **方案**：显示“方案/”文件夹中的文档，可按状态筛选，也可以从文档发起开工。

这两个分区各有自己的层级，按返回会先退回上一级，再退出整个资料库。

Wiki 分区支持筛选标题、摘要或条目标识，并打开正文阅读。文档随应用版本分发，不从网站即时更新；内部测试版显示的是该测试版本打包的文档。

## 返回与刷新

- 内部层级：返回上一级。
- 最外层：返回聊天。
- 列表与刚完成的任务不同步时：等待回合结束，或使用页面提供的刷新按钮。
- 切换分区时存在未保存的编辑草稿，页面可能要求确认。

## 提示

- 先在左侧选好项目，再进入资料库，能减少“看不到内容”的困惑。
- 上传资料后确认落点，避免把文件放进错误项目。
- 方案与记忆的编辑使用同一套文档编辑器，保存后再切换页面。

## 已知问题

- 没有选择项目时，部分创建或上传操作不可用。
- 资料列表依赖会话结束后的刷新，刚生成的文件可能稍后才出现。
