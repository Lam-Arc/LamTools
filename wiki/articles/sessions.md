# 会话

**会话**（Session）是 Sunday 保存一段连续对话与运行记录的单位。会话可以在侧栏中查找、切换、重命名、导出或删除。

| 信息框 | |
|---|---|
| 类型 | 对话容器 |
| 入口 | 聊天区“新会话”；左侧项目分组中的现有会话 |
| 归属 | 可属于某个项目，也可不归属项目 |
| 草稿 | 按会话分别保存 |
| 标题 | 通常自动生成，也可手动修改 |
| 导出格式 | Markdown、TXT、JSONL、Agent Handoff、完整归档 |

## 概述

会话保存消息、工具调用与运行结果。切换会话时，Sunday 会载入对应历史，并把输入草稿按会话分别保存，因此离开再回来不会丢失未发送的文字。<sup>[1][2]</sup>

会话与项目是两个维度：会话是讨论，项目是工作目录与规则。一个项目可以有多条会话，一条会话也可以不属于任何项目。

## 开始和切换

- 点击侧栏“新会话”开始一段新对话。
- 从项目的新增会话按钮创建时，会话归属该项目。
- 选择已有会话会载入历史消息和当前上下文。

应用正在加载历史时，发送操作会暂时受限；等消息显示完成后再继续。会话标题通常由对话内容生成，也可以通过标题编辑操作修改。

## 查找与整理

| 操作 | 位置 | 说明 |
|---|---|---|
| 筛选 | 侧栏“搜索项目和会话” | 只过滤当前列表，不是全局搜索 |
| 折叠 | 项目分组、最近分区 | 减少侧栏占用 |
| 展开 | “展开另外…个会话” | 查看项目下更多记录 |
| 重命名 | 会话菜单 | 便于以后查找 |
| 导出 | 会话菜单 | 见[会话导出](session-export.md) |
| 删除 | 会话菜单 | 从列表与存储中移除记录 |

删除会话会移除对应记录，整理前核对名称，避免误删仍需引用的工作过程。<sup>[1]</sup>

## 状态与恢复

侧栏会显示会话当前状态，例如运行中或待处理，用来判断是否可以继续发送。运行中的会话可以从聊天区停止。

如果应用意外关闭，重新打开后可以从侧栏选回已保存的会话。会话依赖本地应用数据和所属项目目录；移动或删除项目文件不会自动重建目录内容。

会话没有出现在当前列表时，按以下顺序查找：

1. 清除侧栏筛选。
2. 展开相应项目分组。
3. 使用[全局搜索](search.md)查找会话或消息。

## 会话与项目的关系

- 会话归属项目后，项目和会话会一起显示在侧栏分组中。
- 在项目内新建会话，会自动带上该项目的工作目录。
- 不归属项目的会话仍然可用，但没有项目规则与项目目录上下文。

## 提示

- 为不同任务建立不同会话，避免一条会话过长。
- 切换会话前不必复制草稿，草稿会按会话保存。
- 重要会话先导出，再删除或整理。

## 已知问题

- 删除会话不可撤销。
- 标题自动生成可能重复，查找时结合项目与时间判断。
