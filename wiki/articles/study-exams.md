# Study 测验和成绩

**Study 测验**（Study exams）是学习工作区用来检查是否真正掌握知识的功能。测验包含题目、参考答案、分值和评分标准，支持保存作答草稿，并在明确提交后整份批阅。

| 信息框 | |
|---|---|
| 类型 | 测验与评分 |
| 题目形式 | 选择题、书面题 |
| 作答草稿 | 支持逐题保存 |
| 批阅时机 | 明确提交或要求批阅后 |
| 帮助记录 | 考试中求助会被记录 |
| 掌握判定 | 一次测验不能代表整个学科 |

## 概述

测验用来判断能否独立解释、选择方法和应用知识，而不是检查是否看过材料。<sup>[1][2]</sup>

一次短测不能代表整个学科水平。

## 创建和作答

提出范围、目标和题数，例如：

> 围绕本周学过的线性方程出四道题，包含方法选择和计算。

规则：

- 系统根据目标设计题目。
- 可以逐题保存草稿。
- 必要时可以提交图片作答。
- 保存草稿不等于提交。
- 只有明确提交或要求批阅后才开始整份评分。
- 正式展示时，参考答案不会提前附在题目后。

## 评分和求助

评分会参考：

- 预设答案。
- 评分标准。
- 分值。

合理的等价表达和替代解法应被接受。

看不清的图片或符号会先标记待澄清，不应猜错答案。

考试过程中求提示时，帮助程度会被记录。已获得帮助的部分不能作为独立掌握证据。

可以要求复核某题，指出认为有效的步骤；系统会检查原题和评分理由。

## 掌握度边界

| 情况 | 对掌握判定的影响 |
|---|---|
| 独立完成且答案正确 | 可支持相关知识点 |
| 获得较多帮助 | 不能作为独立掌握证据 |
| 未测到的知识点 | 保持未确认 |
| 答案不清 | 先澄清，不猜分 |

考试成绩可以为知识点提供证据，但不等于评价能力或智力。一次满分短测也不应直接推出高掌握。

提交前检查题目范围和答案。发现题目本身有歧义或标准错误时，应修正评分。

测验覆盖面很广时，应说明题目只是抽样。

## 提示

- 先说明这次要检查哪些知识点。
- 不会时先要提示，不要直接看答案。
- 复核时指出具体步骤，而不是只说“我觉得对”。

## 已知问题

- 评分依赖预设答案与标准，主观题可能有争议。
- 一次测验只覆盖抽样范围。
