# 工作流中的人工审批和待办

**工作流人工任务**（Human tasks）是工作流在需要人判断时暂停、并把事项交给用户处理的机制。它分为人工审批与等待事件两类。

| 信息框 | |
|---|---|
| 类型 | 人工任务 |
| 入口 | Workflow 的人工任务区域 |
| 类型 | 人工审批、等待事件 |
| 提交内容 | 批准/拒绝，或 JSON 对象数据 |
| 处理结果 | 流程继续、走拒绝分支或保持等待 |
| 校验 | JSON 必须是对象 |

## 概述

工作流可以停在需要人决定的步骤上。人工审批节点要求批准或拒绝；等待事件节点等待指定事件或数据。两种任务都出现在待办列表中。<sup>[1][2]</sup>

待办列表显示任务状态、所属工作流、截止时间与可填写的提交数据。

## 查看并处理待办

1. 在 Workflow 的人工任务区域刷新列表。
2. 选择一条待办查看详情。
3. 按任务类型处理。

详情可能显示：

- 工作流名称。
- 事件类型。
- 负责人与分组。
- 截止时间。
- 表单说明。

审批任务选择批准或拒绝；等待事件任务提交对应数据。界面会校验 JSON 格式，只有顶层为对象时才可提交。

## 提交前核对

检查任务来源和表单字段，确认：

- 批准的动作是什么。
- 数据范围是否正确。
- 目标是否符合预期。

批准可能让流程继续执行后续命令、调用模型或改动数据。拒绝应使流程按拒绝分支处理。

提交后查看状态和审计记录，确认事件确实被接受。

对截止时间或负责人不清楚的任务，先在任务上下文中核实，不要随意填造信息。

## 没有任务或无法提交

| 现象 | 可能原因 |
|---|---|
| 列表为空 | 没有运行到达人工节点，或仍在等待其他事件 |
| 提交失败 | JSON 语法错误、顶层不是对象 |
| 无法重复提交 | 任务已完成或已取消 |

刷新并检查运行队列与节点状态。重复刷新不会代替完成任务。

人工处理的数据会成为工作流输入，应避免放入不必要的机密。

## 提示

- 批准前先看它会让流程做什么，不只看按钮文字。
- 提交的数据只填流程真正需要的字段。
- 截止时间紧的任务优先处理，避免流程长期挂起。

## 已知问题

- 已完成或取消的任务不能再次提交。
- 待办列表不会自动代替运行队列的诊断。
