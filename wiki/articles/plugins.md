# 插件

**插件**（Plugin）是 Sunday 中可独立安装、启用和配置的扩展单元。一个插件可以提供界面、工具、技能、钩子和 MCP 能力，也可以只提供其中一部分。

| 信息框 | |
|---|---|
| 类型 | 扩展单元 |
| 入口 | 应用侧栏“插件” |
| 安装来源 | 本机目录、`.zip` 文件、GitHub Release 地址 |
| 可提供 | 界面、工具、技能、钩子、MCP 配置 |
| 内置插件 | 可以禁用，不能卸载 |
| 卸载影响 | 删除插件目录 |

## 概述

插件把一组相关能力打包在一起，避免用户逐个配置工具和界面。安装插件不等于自动启用所有能力；实际可用性还受工具模式、权限和依赖服务影响。<sup>[1][2]</sup>

Sunday 自带若干内置插件，例如工作流、学习工作区、方案、网页搜索、图片生成、Git 和桌宠。它们和用户安装的插件出现在同一个管理页面。

## 安装插件

支持三种来源：

| 来源 | 需要提供 |
|---|---|
| 本机目录 | 含插件定义的目录路径 |
| 压缩包 | `.zip` 文件 |
| GitHub Release | 具体的 Release 资源地址 |

提交后等待插件出现在列表中。压缩包可能带一层外层目录，应用会定位真正包含插件定义的目录。

只安装来源可信、符合工作需要的内容。插件可以携带工具与钩子，能够执行本机操作。

## 启用与配置

- 插件条目可以切换启用状态。
- 有配置项的插件会显示“配置”入口。
- 按插件提供的表单填写并保存。
- 插件详情会列出它的工具和其他资源，可能显示权限标记。

配置不生效时，重新打开配置卡片检查保存值，并确认插件处于启用状态。

## 内置插件与卸载

| 类型 | 启用/禁用 | 卸载 |
|---|---|---|
| 用户安装的插件 | 可以 | 可以，删除插件目录 |
| 内置插件 | 可以 | 不可以 |

卸载会同时删除插件目录，操作前确认插件名称和数据范围。禁用只是让它暂时不参与工作，不会删除文件。

## 能力与限制

插件提供的能力不一定在每次任务中都用上：

- 工具是否可用受工具模式影响。
- 执行是否需要确认受权限影响。
- MCP 工具需要服务实际连接。
- 插件声明的平台范围决定它是否出现在当前环境。

网络设置变更后，已连接的 MCP 服务或后台命令可能需要重启应用。

## 故障排查

| 现象 | 先检查 |
|---|---|
| 插件不在列表 | 安装来源、平台适用范围、刷新列表 |
| 工具找不到 | 插件是否启用、工具模式是否包含 |
| 配置不生效 | 是否保存、是否重新打开配置卡片 |
| 网络下载失败 | Release 地址、代理设置 |
| 插件界面打不开 | 切回聊天、刷新、查看错误提示 |

## 提示

- 先安装、再启用、最后配置，分三步确认问题出在哪。
- 只给可信插件配置密钥。
- 插件变多后，用工具模式控制哪些能力参与工作。

## 已知问题

- 内置插件只能禁用，不能卸载。
- 插件能力依赖外部服务时，服务不可用会导致工具失败。
