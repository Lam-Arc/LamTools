# QQ 机器人

这个插件把 LamTools 接到 QQ 私聊和群聊。QQ 消息由插件后端接收，按「一个私聊/群聊 = 一个持久子会话」交给宿主模型；回复通过 QQ 网关发回。

## 对模型可见的工具

- `qqbot_send_file`：把本地文件发到当前 QQ 会话。用户说「发给我 / 传到群里 / 把结果发 QQ」时用。`file_path` 必须是磁盘上已存在的绝对路径；默认发回当前会话。
- `qqbot_describe_image`：看一张图片并返回文字。用户发来图片，或任务需要 OCR、读图表、看截图时用。`image` 可以是本地绝对路径或 http(s) URL；给 `prompt` 说明你要什么。
- `qqbot_status`：查看绑定、网关和会话状态。
- `qqbot_bind_start`：开始扫码绑定，返回二维码和链接。只在用户明确要绑定/换绑时用。

## 边界

- 群聊默认只有 @机器人 才会触发回复；未 @ 的消息只进入历史缓冲。
- 私聊默认所有人可用；群聊默认所有人可用。访问控制在插件设置里改成白名单或禁用。
- 发送文件受路径白名单限制（插件媒体目录、当前项目目录、设置里的额外目录）。超出的路径会被拒绝。
- 机器人不会主动私聊陌生人；QQ 平台对主动消息有频率限制。被动回复超限时插件会降级为主动消息，仍受平台限制。
