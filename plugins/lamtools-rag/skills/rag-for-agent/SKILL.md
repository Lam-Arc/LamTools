# rag-for-agent：RAG 查询与回答协议

## 检索协议（工具选择）

| 场景 | 工具 |
|---|---|
| 问题涉及工作区文档（合同、手册、代码、笔记） | `rag_search(query, scope="docs")` |
| 问题涉及"之前/上次/以前讨论过/你以前说过" | `rag_search_sessions(query, filters={...})` |
| 需要查看命中文档某页完整原文 | `rag_read(doc_id, page)` |
| 检索结果片段不够、需要整轮上下文 | `rag_search_sessions` 后按 message_id 精读（P2 起支持） |

**注意**：普通问题不要混入会话历史（默认 scope=docs）；历史问题不要用 rag_search 搜文档。按工具描述选择，不要靠猜测。

## 引用规范（强制）

所有基于检索的回答必须带引用，格式：

- 文档引用：`[p.12]` 页码 + 引号内原文精确片段；
- 会话引用：`[会话:会话标题, msg:<message_id>]` + 引号内原文片段；
- 引用必须来自本次检索返回的命中（不得编造页码或 message_id）。

## 答案闸门（强制）

最终回答前**必须调用 `submit_answer`** 提交"答案 + 引用列表"。校验规则：

1. 引用格式合法（页码存在 / message_id 存在）；
2. 引用目标在本次检索命中集内；
3. 原文片段与索引文本一致（归一化后）。

校验失败会返回原因——根据原因修正（补引用/改引用/重新检索）后再次提交，**不要忽略校验直接输出**。

## 检索结果不足时

- 命中为空：先确认索引是否存在（无则引导 rag-indexer）；再尝试改写查询（换措辞、拆短语）；
- 命中不相关：换查询角度或增加过滤器；
- 明确告知用户"索引中没有相关内容"，不要用模型记忆硬答（防幻觉第一原则）。

## 跨文档对比类问题

多步检索：先分别检索各主题 → 汇总对比 → 引用每一步的命中。保持引用与来源一一对应。
